# prebookingtheslotmultipletimes

Nomadia Delivery allows dispatchers to pre-book and reschedule time slots multiple times using the original booking link. This feature simplifies scheduling changes without requiring new booking link creation. Users can quickly update delivery timings to ensure seamless operational planning.

### Getting Started

Prerequisites:
- Active access to the Nomadia Delivery platform.
- An existing slot booking scheduled for a delivery.
- Access to the original booking link received during first confirmation.

Initial Setup Steps:
1. Locate the initial confirmation message containing the **Booking Link**.

2. Click the **Booking Link** to open the schedule management page.

![Booking Link – User clicks original link to access schedule.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_16_to_0_to_25.gif "Booking Link – Accessing booking schedule via original link.")

3. View the landing page displaying your currently scheduled date and timing details.

![Landing Page – Displaying currently scheduled date and timing.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_35.png "Landing Page – Current reservation status and timing details are visible.")

### Feature Overview

- **Booking Link**: Re-opens the scheduling page using the original link sent during initial slot booking.

![Booking Link – Accessing the scheduling page using the original link.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_16_to_0_to_25.gif "Booking Link – Transition from link click to schedule page view.")

- **Scheduled Date and Timing**: Shows the current confirmed date and time slot for the delivery.

![Scheduled Date and Timing – Shows current booking details.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_42.png "Scheduled Date and Timing – Displays current reserved date and time.")

- **Reschedule Option**: Opens available alternative time slots for rebooking.

![Reschedule Option – Button located below current booking details.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_48.png "Reschedule Option – Action button to initiate rebooking.")

- **Available Date and Timings**: Displays selectable date and time options for pre-booking.

![Available Date and Timings – Grid of available time slots.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_58.png "Available Date and Timings – View of alternative slot options.")

- **Choose / Book Button**: Confirms and saves the selected time slot.

![Choose Button – Confirming new slot selection.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_1_to_01_to_1_to_10.gif "Choose Button – Selecting preferred slot and confirming booking.")

### How To: Reschedule a Pre-Booked Slot

1. Click the original **Booking Link** received when booking the first slot.

![Booking Link – Opening schedule page from initial link.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_16_to_0_to_25.gif "Booking Link – Navigating to booking page via original URL.")

2. Confirm your current slot details under **Scheduled Date and Timing**.

![Scheduled Date and Timing – Displaying existing reservation details.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_42.png "Scheduled Date and Timing – Verification of existing slot schedule.")

3. Click the **Reschedule Option** located below the current schedule details.

![Reschedule Option – Clicking button to access timing options.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_48_to_0_to_50.gif "Reschedule Option – Action sequence to open timing choices.")

4. Review the list of **Available Date and Timings**.

![Available Date and Timings – Listing alternative schedules.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_0_to_58.png "Available Date and Timings – Selection menu for new timings.")

5. Select your preferred timing and click **Choose** to book the slot.

![Choose Button – Selecting new slot and finalizing booking.]({IMAGE_BASE_PATH}prebookingtheslotmultipletimes-prebookingtheslotmultipletimes_timestamp_1_to_01_to_1_to_10.gif "Choose Button – Finalizing slot reservation.")

### Productivity Tips

- 💡 **Reuse Original Booking Links**: Re-open the same booking link received during initial reservation to quickly change slot timings without generating new requests.
