# Case Studies

This section collects Nomadia Delivery case studies, each walking through a specific task from start to finish.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the area covered by the case study you want to follow.
* Open the case study you need and review its own **Before you begin** section for the prerequisites of that task.

## Feature overview

* **Study Creation with Primary Zone**: Create seasonal plans that activate automatically at the right time.
* **Subsector using postal code**: Automatically split a primary zone into subzones based on its associated postal codes.
* **Sub sectorize primary zone**: Split a primary zone into smaller, balanced territories automatically.
* **Assigning Sub Zones**: Assign map shapes to specific teams and deliverers so every delivery stop has a clear owner.
* **Assigning zones to missions**: Automatically associate new missions with predefined delivery sectors.
* **Optimizing missions for Agency**: Automate the process from mission selection to optimized route creation.
* **Reduced fixed duration**: Adjust time estimates for multiple packages at a single location.
* **Route Blocking Settings**: Prevent drivers from starting routes containing high-value items until a planner reviews them.
* **Creating Backup Zone**: Handle emergency subcontractor no-shows by creating temporary secondary sectors.
* **Subcontractor Swap to Backup Zone**: Remap affected missions to a backup zone and a replacement subcontractor in one action.
* **Subcontractor Swap to Primary Zone**: Restore missions to their original primary zone configuration in a single action.
* **Pudo configuration**: Let drivers leave packages at secure pickup and drop-off points when customers are unavailable.
* **Multi Leg Missions**: Track parcels across multiple hubs and agencies from first-mile pickup to last-mile delivery.
* **Reassign Zones Manually**: Move missions to a new territory layout when automatic triggers do not apply.
* **Reverse Logistics**: Trigger, plan, and execute returns without leaving the platform.
* **No Route Mode**: Focus on mission management and traceability by hiding features related to route planning.

## Tips

{% hint style="info" %}
**Choose the right swap**: Use **Subcontractor Swap to Backup Zone** when a primary subcontractor is unavailable, and **Subcontractor Swap to Primary Zone** to restore missions to their original primary zone configuration.
{% endhint %}

{% hint style="info" %}
**Manual or automatic zones**: Use **Reassign Zones Manually** when switching between studies or seasonal configurations where automatic triggers do not apply.
{% endhint %}
