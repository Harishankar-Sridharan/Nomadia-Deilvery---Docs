# Assign to Subcontractors

Configure the iFrame for subcontractors and communicate with them through the integrated external interface when assigning missions in No Route mode.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page.
* Make sure your company uses No Route mode and has subcontractors to whom you assign missions.

## Feature overview

* **Iframe Configuration**: Customize the display of external URLs for specific subcontractor users.
* **Interacting with Iframe**: Send status updates and messages to subcontractors through an integrated external interface without leaving the main application.

## Features

* [Iframe Configuration](iframe-configuration.md)
* [Interacting with Iframe](intracting-with-iframe.md)

## Tips

{% hint style="info" %}
**Configure first**: Set up **Iframe Configuration** for the subcontractor before you use **Interacting with Iframe** to communicate through the integrated external interface.
{% endhint %}
