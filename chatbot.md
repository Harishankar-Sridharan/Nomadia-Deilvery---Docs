# chatbot

The **chatbot** feature in **Nomadia Delivery** provides an automated virtual assistant for dispatchers and planners. You can select predefined questions or type custom queries directly in the typing window. This helps you resolve operational questions quickly without leaving the platform.

### Getting Started

Ensure you meet all system requirements before accessing the feature.

- Active **Nomadia Delivery** account with dispatcher or planner permissions.
- Supported web browser with an active internet connection.

1. Log into **Nomadia Delivery**.
2. Locate the top right navigation bar next to **Management**.

![Chatbot Location – Chatbot option displayed next to Management in top right corner.](chatbot-chatbot_timestamp_0_to_12.png "Chatbot Location – Chatbot option displayed next to Management in top right corner.")

3. Click the **Chatbot icon**.

![Virtual Assistant Flow – Clicking the chatbot icon opens the assistant interface.](chatbot-chatbot_timestamp_0_to_12_to_0_to_14.gif "Virtual Assistant Flow – Clicking the chatbot icon opens the assistant interface.")

4. Select **Hello, I am your virtual assistant**.

![Select Assistant Prompt – Clicking the greeting banner below the header.](chatbot-chatbot_timestamp_0_to_18_to_0_to_20.gif "Select Assistant Prompt – Clicking the greeting banner below the header.")

### Feature Overview

- **Chatbot icon**: Opens the virtual assistant interface from the top navigation bar.

![Chatbot Icon – Visible button next to Management in top right corner.](chatbot-chatbot_timestamp_0_to_05_to_0_to_12.gif "Chatbot Icon – Visible button next to Management in top right corner.")

- **Virtual Assistant option**: Banner displaying "Hello, I am your virtual assistant" to start interaction.

![Virtual Assistant Banner – Greeting prompt located below the main header.](chatbot-chatbot_timestamp_0_to_14_to_0_to_18.gif "Virtual Assistant Banner – Greeting prompt located below the main header.")

- **Predefined Questions**: List of ready-to-use questions and answers for quick self-service.

![Predefined Questions – Built-in questions and answers list.](chatbot-chatbot_timestamp_0_to_20_to_0_to_26.gif "Predefined Questions – Built-in questions and answers list.")

- **Typing Window**: Input field where you enter custom inquiries.

![Typing Window – Text field for entering custom questions.](chatbot-chatbot_timestamp_0_to_26_to_0_to_33.gif "Typing Window – Text field for entering custom questions.")

- **Send button**: Submits your typed question to the virtual assistant.

![Send Button – Action button for submitting typed text.](chatbot-chatbot_timestamp_0_to_47_to_0_to_52.gif "Send Button – Action button for submitting typed text.")

- **Typing Indicator**: Displays animated feedback while the assistant generates an answer.

![Typing Indicator – Visual state indicating response generation.](chatbot-chatbot_timestamp_0_to_56_to_1_to_01.gif "Typing Indicator – Visual state indicating response generation.")

### How To: Access Predefined Questions

1. Click the **Chatbot icon** in the top right header.

![Click Chatbot Icon – Opening the chatbot interface from navigation bar.](chatbot-chatbot_timestamp_0_to_12_to_0_to_14.gif "Click Chatbot Icon – Opening the chatbot interface from navigation bar.")

2. Click **Hello, I am your virtual assistant**.

![Click Greeting Banner – Selecting the virtual assistant banner.](chatbot-chatbot_timestamp_0_to_18_to_0_to_20.gif "Click Greeting Banner – Selecting the virtual assistant banner.")

3. Review the listed **Predefined Questions and Answers**.

![View Predefined Questions – Reviewing ready-to-use answers.](chatbot-chatbot_timestamp_0_to_20_to_0_to_26.gif "View Predefined Questions – Reviewing ready-to-use answers.")

### How To: Ask a Custom Question

1. Click inside the **Typing Window**.

![Select Typing Window – Clicking the text input field.](chatbot-chatbot_timestamp_0_to_26_to_0_to_33.gif "Select Typing Window – Clicking the text input field.")

2. Type your question into the **Typing Window**.

![Enter Question – Typing query text into input area.](chatbot-chatbot_timestamp_0_to_33_to_0_to_47.gif "Enter Question – Typing query text into input area.")

3. Click **Send**.

![Click Send Button – Submitting the typed question.](chatbot-chatbot_timestamp_0_to_47_to_0_to_52.gif "Click Send Button – Submitting the typed question.")

4. Observe the **Typing Indicator** while the response generates.

![Response Processing – Assistant typing the answer.](chatbot-chatbot_timestamp_0_to_56_to_1_to_01.gif "Response Processing – Assistant typing the answer.")

5. Read the displayed answer based on your question.

![View Answer Response – Receiving answer content.](chatbot-chatbot_timestamp_1_to_01_to_1_to_06.gif "View Answer Response – Receiving answer content.")

### Productivity Tips

- 💡 **Predefined Questions**: Review built-in questions for instant answers to common topics.
- 💡 **Specific Queries**: Type clear questions in the typing window to receive targeted answers.
