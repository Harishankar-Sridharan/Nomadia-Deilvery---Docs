# Table view

The **table view** feature provides a structured tabular view for managing route information in **Nomadia Delivery**. Planners need it to monitor route fulfillment, driver assignments, and mission counts in a consolidated format. You will gain full control over displayed route columns, stop views, and summary footer calculations.

## Before you begin

Prerequisites and system requirements:

* Access to the **Missions** section in **Nomadia Delivery**.
* Pre-configured routes created in the system.

Initial setup steps:

1. Select **Missions** from the main menu.
2. Scroll down to the **Routes** section.
3. Locate the **Table View Menu** next to **Actions**.
4. Click **Table View Menu** to change the **Routes** display to table view.

![Click Table View Menu to change the Routes display to table view](.gitbook/assets/TableView_BeforeBegin_001.gif)

## Feature overview

* **Eye Icon**: View assigned routes directly on the interactive map.
* **Filter View**: Hide or show the column filter row across the table.
* **Status**: Displays the current operational status of each route.
* **Route Name**: Displays the designated route name and its assigned date.
* **Route Fulfillment**: Indicates route fulfillment status with a yes or no value.
* **Deliverer Name**: Displays the name of the assigned driver or deliverer.
* **Assigned Missions**: Displays the total count of missions assigned to the route.
* **Working Time**: Displays the calculated working time required for the route.
* **Mission Breakdown Counts**: Displays breakdown totals for deliveries, pickups, visits, cross docking, drop shipping, and signed pickups.
* **Customize List**: Sets which fields are displayed in the route or stop section.
* **Footer**: Selects table columns to compute summary calculations like mission totals.

## Customize route view fields

1. Click **Actions** in the route menu.

![Click Actions in the route menu](.gitbook/assets/TableView_CustomizeRouteViewFields_001.png)

2. Select **Customize List** from the menu options.

![Select Customize List from the menu options](.gitbook/assets/TableView_CustomizeRouteViewFields_002.gif)

3. Select the fields you want to display in the route section.
4. Click the **Right Arrow** to add selected fields to the display list.
5. Click **Save** to apply your route field selections.

![Click Save to apply your route field selections](.gitbook/assets/TableView_CustomizeRouteViewFields_003.png)

## View route stops

1. Click any **Route** row in the table.
2. Review individual stop details for the selected route.
3. Click **Back** to return to the main route view.

![Click Back to return to the main route view](.gitbook/assets/TableView_ViewRouteStops_001.png)

## Customize stop view fields

1. Click **Actions** and select **Customize List**.
2. Select **Stops** from the customization panel.

![Select Stops from the customization panel](.gitbook/assets/TableView_CustomizeStopViewFields_001.gif)

3. Select the fields to display in the stop view.
4. Click **Save** to confirm your stop view settings.

![Click Save to confirm your stop view settings](.gitbook/assets/TableView_CustomizeStopViewFields_002.png)

## Calculate column sums in the footer

1. Click **Footer** inside the **Customize List** window.

![Click Footer inside the Customize List window](.gitbook/assets/TableView_CalculateColumnSumsFooter_001.gif)

2. Select a target column, such as **Assigned Mission Number**.

![Select a target column, such as Assigned Mission Number](.gitbook/assets/TableView_CalculateColumnSumsFooter_002.png)

3. Click **Sum** to enable total calculation.

![Click Sum to enable total calculation](.gitbook/assets/TableView_CalculateColumnSumsFooter_003.png)

4. Click **Save** to apply footer settings.

![Click Save to apply footer settings](.gitbook/assets/TableView_CalculateColumnSumsFooter_004.gif)

5. View the calculated total sum in the table footer row.

![View the calculated total sum in the table footer row](.gitbook/assets/TableView_CalculateColumnSumsFooter_005.png)

## Tips

{% hint style="info" %}
**Filter View Toggle**: Click **Filter View** to hide the filter row and maximize the table viewing area.
{% endhint %}

{% hint style="info" %}
**Automatic Sum Calculations**: Use **Footer** sum options to calculate total assigned missions across rows instantly.
{% endhint %}

{% hint style="info" %}
**Direct Stop Access**: Click any route row directly to open the stop view without going through secondary menus.
{% endhint %}
