# tableview

The **tableview** feature provides a structured tabular view for managing route information in **Nomadia Delivery**. Planners need it to monitor route fulfillment, driver assignments, and machine counts in a consolidated format. You will gain full control over displayed route columns, stop views, and summary footer calculations.

### Getting Started

Prerequisites and system requirements:
- Access to the **Machines** section in **Nomadia Delivery**.
- Pre-configured routes created in the system.

Initial setup steps:
1. Select **Machines** from the main menu.

2. Scroll down to locate the **Routes** section.

3. Locate the **Table View Menu** next to **Actions**.

4. Click **Table View Menu** to change the **Routes** display to table view.

### Feature Overview

- **Eye Icon**: View assigned routes directly on the interactive map.

  ![Frame at 0:32](tableview-tableview_timestamp_0_to_32.png "Eye Icon – Displays selected routes on the map.")

- **Filter View**: Hide or show the column filter row across the table.

  ![Frame at 0:40](tableview-tableview_timestamp_0_to_40.png "Filter View – Toggles the visibility of the column filter row.")

- **Status**: Displays the current operational status of each route.

  ![Frame at 0:48](tableview-tableview_timestamp_0_to_48.png "Status – Shows the active route fulfillment status.")

- **Route Name**: Displays the designated route name and its assigned date.

  ![Frame at 0:54](tableview-tableview_timestamp_0_to_54.png "Route Name – Displays the assigned route name and date.")

- **Route Fulfillment**: Indicates route fulfillment status with a yes or no value.

  ![Frame at 1:04](tableview-tableview_timestamp_1_to_04.png "Route Fulfillment – Shows yes or no fulfillment state.")

- **Deliverer Name**: Displays the name of the assigned driver or deliverer.

  ![Frame at 1:10](tableview-tableview_timestamp_1_to_10.png "Deliverer Name – Identifies the person assigned to the route.")

- **Assigned Machines**: Displays the total count of machines assigned to the route.

  ![Frame at 1:14](tableview-tableview_timestamp_1_to_14.png "Assigned Machines – Displays the total machine count assigned.")

- **Working Time**: Displays the calculated working time required for the route.

  ![Frame at 1:18](tableview-tableview_timestamp_1_to_18.png "Working Time – Displays estimated working duration.")

- **Machine Breakdown Counts**: Displays breakdown totals for deliveries, pickups, visits, cross docking, drop shipping, and signed pickups.

  ![Frame at 1:22](tableview-tableview_timestamp_1_to_22.png "Machine Breakdown Counts – Displays job counts by specific activity type.")

- **Customizer List**: Configures which fields display in the route or stop section.

  ![Frame at 1:46](tableview-tableview_timestamp_1_to_46.png "Customizer List – Opens menu to select visible table columns.")

- **Footer**: Selects table columns to compute summary calculations like machine totals.

  ![Frame at 2:48](tableview-tableview_timestamp_2_to_48.png "Footer – Enables sum calculations across table columns.")

### How To: Customize Route View Fields

1. Click **Actions** in the route menu.

   ![Frame at 1:42](tableview-tableview_timestamp_1_to_42.png "Actions – Opens the action options drop-down menu.")

2. Select **Customizer List** from the menu options.

   ![Flow 1:46 to 1:52](tableview-tableview_timestamp_1_to_46_to_1_to_52.gif "Customizer List – Opens field selection for the route section.")

3. Select the fields you want to display in the route section.

4. Click the **Right Arrow** to add selected fields to the display list.

   ![Frame at 2:02](tableview-tableview_timestamp_2_to_02.png "Right Arrow – Adds selected fields to the active display list.")

5. Click **Save** to apply your route field selections.

   ![Flow 2:02 to 2:14](tableview-tableview_timestamp_2_to_02_to_2_to_14.gif "Save – Saves customized column settings for the route view.")

### How To: View Route Stops

1. Click any **Route** row in the table.

   ![Flow 2:14 to 2:26](tableview-tableview_timestamp_2_to_14_to_2_to_26.gif "Route Row – Switches table view from route overview to stop view.")

2. Review individual stop details for the selected route.

   ![Frame at 2:26](tableview-tableview_timestamp_2_to_26.png "Stop View – Displays all stops associated with the selected route.")

3. Click **Back** to return to the main route view.

   ![Flow 2:26 to 2:34](tableview-tableview_timestamp_2_to_26_to_2_to_34.gif "Back Button – Navigates back from stop view to route table view.")

### How To: Customize Stop View Fields

1. Click **Actions** and select **Customizer List**.

2. Select **Stops** from the customization panel.

   ![Flow 2:34 to 2:40](tableview-tableview_timestamp_2_to_34_to_2_to_40.gif "Stops Tab – Switches customizer settings to stop view fields.")

3. Select the fields to display in the stop view.

   ![Frame at 2:40](tableview-tableview_timestamp_2_to_40.png "Field Selection – Configures visible columns for stop view.")

4. Click **Save** to confirm your stop view settings.

### How To: Calculate Column Sums in the Footer

1. Click **Footer** inside the **Customizer List** window.

   ![Flow 2:48 to 2:54](tableview-tableview_timestamp_2_to_48_to_2_to_54.gif "Footer – Opens table calculation settings.")

2. Select a target column, such as **Assigned Machine Number**.

   ![Frame at 3:00](tableview-tableview_timestamp_3_to_00.png "Column Selection – Selects assigned machine number for footer calculation.")

3. Click **Sum** to enable total calculation.

   ![Frame at 3:04](tableview-tableview_timestamp_3_to_04.png "Sum Option – Calculates total sum for the chosen column.")

4. Click **Save** to apply footer settings.

   ![Flow 3:12 to 3:14](tableview-tableview_timestamp_3_to_12_to_3_to_14.gif "Save Button – Applies calculation settings and updates table footer.")

5. View the calculated total sum in the table footer row.

   ![Frame at 3:14](tableview-tableview_timestamp_3_to_14.png "Table Footer – Displays calculated sum total of assigned machines.")

### Productivity Tips

- 💡 **Filter View Toggle**: Click **Filter View** to hide the filter row and maximize table viewing area.
- 💡 **Automatic Sum Calculations**: Use **Footer** sum options to calculate total assigned machines across rows instantly.
- 💡 **Direct Stop Access**: Click any route row directly to open stop view without navigating secondary menus.
