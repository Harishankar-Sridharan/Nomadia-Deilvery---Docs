# Manage Tickets

The mission ticketing system in Nomadia Delivery simplifies the process of managing mission- or parcel-related queries. It allows contractors to raise tickets directly from the mission editor via the Help tab. This ensures that any issues or concerns that arise during a mission are reported quickly and resolved efficiently.

## Before you begin

* To access the ticket module, you must have the appropriate rights granted by administrators.
