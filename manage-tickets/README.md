# Manage Tickets

The mission ticketing system in Nomadia Delivery simplifies the process of managing mission- or parcel-related queries. It allows contractors to raise tickets directly from the mission editor via the Help tab. This ensures that any issues or concerns that arise during a mission are reported quickly and resolved efficiently.

## Before you begin

* To access the ticket module, you must have the appropriate rights granted by administrators.

## Feature overview

* **Mission ticketing system**: Simplifies the management of mission- or parcel-related queries.
* **Help tab**: The tab in the mission editor from which contractors raise tickets.
* **Activating the Ticket Module**: Grant a user the necessary rights under the Tickets section of their roles and rights.
* **Creating a Ticket**: Create, reply to, close, reopen, and bulk edit tickets.

## Tips

{% hint style="info" %}
**Report issues early**: Raise a ticket from the mission editor as soon as an issue or concern arises during a mission, so it is reported quickly and resolved efficiently.
{% endhint %}

{% hint style="warning" %}
**Rights required**: You cannot access the ticket module until an administrator grants you the appropriate rights.
{% endhint %}
