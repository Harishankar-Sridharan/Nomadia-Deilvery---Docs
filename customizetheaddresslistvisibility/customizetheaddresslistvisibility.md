# Customize the Address Visibility

**Configure field visibility in your address lists** for different user groups. **Control which information is visible or editable** in global and contractor address lists. **Streamline your workspace** and ensure teams only see relevant data.

## Before you begin

Prerequisites:

* Administrative permissions to apply platform-wide settings.

Steps:

1. Open the **Configuration** page.
2. Click on the **Customer addresses block visibility** option.

![Click on the Customer addresses block visibility option](../.gitbook/assets/AddressVisibility_BeforeBegin_001.gif)

## Feature overview

* **Contractor address list**: Manage visibility settings specifically for contractor address lists.
* **Global address list**: Manage visibility settings for the global address list platform-wide.
* **Contact information**: Configure contact fields to be editable or mandatory.
* **General**: Toggle fields like the **Map** and **Opening hours** on or off.
* **Editable**: Allow users to edit field contents by checking this option.
* **Mandatory**: Force users to complete a field before saving changes.

## Customize address block visibility

1. Open the **Configuration** page and click **Customer addresses block visibility**.

![Open the Configuration page and click Customer addresses block visibility](../.gitbook/assets/AddressVisibility_CustomizeAddressBlockVisibility_001.gif)

2. Toggle settings for the **Contractor address list**, **Global address list**, or both.

![Toggle the settings for the contractor and global address lists](../.gitbook/assets/AddressVisibility_CustomizeAddressBlockVisibility_002.gif)

3. Locate the **Contact information** fields.
4. Select the checkbox to set fields to **Editable** by default.
5. Enable the checkbox to make fields **Mandatory**.

![Enable the checkbox to make fields Mandatory](../.gitbook/assets/AddressVisibility_CustomizeAddressBlockVisibility_003.gif)

6. Locate the **General** section.
7. Disable the **Map** and **Opening hours** options.

![Disable the Map and Opening hours options](../.gitbook/assets/AddressVisibility_CustomizeAddressBlockVisibility_004.gif)

8. Click **Save** to apply the changes platform-wide.

![Click Save to apply the changes platform-wide](../.gitbook/assets/AddressVisibility_CustomizeAddressBlockVisibility_005.gif)

## Verify global address list visibility

1. Navigate to the **Address list** menu.

![Navigate to the Address list menu](../.gitbook/assets/AddressVisibility_VerifyGlobalAddressList_001.gif)

2. Click the **Pencil icon** next to the address.

![Click the Pencil icon next to the address](../.gitbook/assets/AddressVisibility_VerifyGlobalAddressList_002.gif)

3. Confirm that the **Map** and **Opening hours** fields are hidden.

![Confirm that the Map and Opening hours fields are hidden](../.gitbook/assets/AddressVisibility_VerifyGlobalAddressList_003.png)

## Verify contractor address list visibility

1. Navigate to the **Contractor** menu.

![Navigate to the Contractor menu](../.gitbook/assets/AddressVisibility_VerifyContractorAddressList_001.gif)

2. Click the **Pencil icon** next to the desired contractor.

![Click the Pencil icon next to the desired contractor](../.gitbook/assets/AddressVisibility_VerifyContractorAddressList_002.gif)

3. Click the **Address list** tab.

![Click the Address list tab](../.gitbook/assets/AddressVisibility_VerifyContractorAddressList_003.gif)

4. Click the **Pencil icon** next to the contractor address.

![Click the Pencil icon next to the contractor address](../.gitbook/assets/AddressVisibility_VerifyContractorAddressList_004.gif)

5. Confirm that the **Map** and **Opening hours** fields are hidden.

## Tips

{% hint style="info" %}
**Default Editability**: Checking a field option sets it to editable by default to save setup time.
{% endhint %}

{% hint style="info" %}
**Flexible Control**: Customize the global list, contractor list, or both simultaneously to suit your workflows.
{% endhint %}

{% hint style="warning" %}
**Platform-Wide Impact**: Saving changes will apply them to all users across the platform immediately.
{% endhint %}
