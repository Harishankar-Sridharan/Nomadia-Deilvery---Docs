# customizetheaddresslistvisibility

**Configure field visibility in your address lists** for different user groups. **Control which information is visible or editable** in global and contractor address lists. **Streamline your workspace** and ensure teams only see relevant data.

### Getting Started

Prerequisites:
*   Access to the **Configuration** menu.
*   Administrative permissions to apply platform-wide settings.

### How To: Customize Address Block Visibility

1. Navigate to **Configuration** and click **Customer addresses block visibility**.

    ![Customer Addresses Block Visibility – Access the configuration settings screen.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_0_to_07_to_0_to_18.gif "Customer Addresses Block Visibility – Accessing the configuration settings screen.")

2. Toggle settings for the **Contractor address list**, **Global address list**, or both.

    ![Address List Selection – Enable or disable lists to receive visibility changes.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_0_to_31_to_0_to_47.gif "Address List Selection – Enabling and disabling lists to receive visibility changes.")

3. Locate the **Contact information** section.

    ![Contact Information Navigation – Locate the contact information fields.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_06_to_1_to_13.gif "Contact Information Navigation – Locating the contact information fields.")

4. Select the checkbox to set fields to **Editable** by default.

    ![Field Configuration – Set fields to editable by default.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_13_to_1_to_18.gif "Field Configuration – Changing fields to editable.")

5. Select the checkbox to make fields **Mandatory**.

    ![Field Configuration – Set fields to mandatory.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_18_to_1_to_26.gif "Field Configuration – Changing fields to mandatory.")

6. Locate the **General** section.

    ![General Section – Locate the general fields.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_26_to_1_to_28.gif "General Section – Accessing the general fields list.")

7. Disable the **Map** and **Opening hours** options.

    ![General Fields Configuration – Disable the map and opening hours options.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_28_to_1_to_37.gif "General Fields Configuration – Disabling map and opening hours.")

8. Click **Save** to apply the changes platform-wide.

    ![Save Configuration – Apply and save address visibility settings platform-wide.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_37_to_1_to_43.gif "Save Configuration – Applying and saving address visibility settings platform-wide.")

### How To: Verify Address List Visibility

1. Navigate to the **Address list** menu.

    ![Address List Menu – Navigate to the global address list.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_43_to_1_to_48.gif "Address List Menu – Navigating to the global address list.")

2. Click the **Pencil icon** next to the address.

    ![Edit Address Details – Select an address to check its details panel.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_48_to_1_to_53.gif "Edit Address Details – Selecting an address to check its details panel.")

3. Confirm that the **Map** and **Opening hours** fields are hidden.

    ![Verification – Confirm map and opening hours are hidden in the global list.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_1_to_59.png "Verification – Confirming map and opening hours are hidden in the global list.")

### How To: Verify Contractor Address List Visibility

1. Navigate to the **Contractor** menu.

    ![Contractor Menu – Navigate to the contractor list section.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_2_to_03_to_2_to_07.gif "Contractor Menu – Navigating to the contractor list section.")

2. Click the **Pencil icon** next to the desired contractor.

    ![Select Contractor – Open the contractor details screen.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_2_to_07_to_2_to_13.gif "Select Contractor – Opening the contractor details screen.")

3. Click the **Addresses** tab.

    ![Contractor Addresses Tab – Select the addresses sub-menu under contractor details.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_2_to_13_to_2_to_17.gif "Contractor Addresses Tab – Selecting the addresses sub-menu under contractor details.")

4. Click the **Pencil icon** next to the contractor address.

    ![Edit Contractor Address – Access specific address details for verification.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_2_to_17_to_2_to_22.gif "Edit Contractor Address – Accessing specific address details for verification.")

5. Confirm that the **Map** and **Opening hours** fields are hidden.

    ![Verification – Confirm map and opening hours are hidden under contractor address list.](customizetheaddresslistvisibility-customizetheaddresslistvisibility_timestamp_2_to_30.png "Verification – Confirming map and opening hours are hidden under contractor address list.")

### Productivity Tips

*   💡 **Default Editability**: Checking a field option sets it to editable by default to save setup time.
*   💡 **Flexible Control**: Customize the global list, contractor list, or both simultaneously to suit your workflows.
*   ⚠️ **Platform-Wide Impact**: Saving changes will apply them to all users across the platform immediately.
