# Home Page

Use the pages in this section to understand and configure the Nomadia Delivery home page.

## Before you begin

* Sign in to **Nomadia Delivery**. The Home Screen is the default landing page.
* Open the **Account icon** at the top-right corner of the Home page to reach **My Preferences**.

## Feature overview

* **Understanding the Home Screen**: Explains the key areas of the Home Screen, such as navigation tabs, My KPI's, and Mission Statistics.
* **Configure the display of mission’s statuses**: Select up to five mission statuses to display on the home page.
* **Configure the Display of my KPI**: Choose the dashboard and a calculation period from Last Day to Last Seven Days.
* **Refresh KPI date and Mission statuses**: Manually refresh the KPIs and statistics on the home page.
