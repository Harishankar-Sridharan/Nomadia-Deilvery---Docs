# Reschedule Configuration

Use this guide to enable end customers to reschedule their delivery or pickup missions in Nomadia Delivery. These features enhance customer convenience and communication by allowing customers to select a time slot that suits their schedule.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Configuration** tab.
* Decide how long before delivery the rescheduling link stays active, from a maximum of 12 hours to a minimum of 3 hours before delivery.

## Feature overview

* **Configure Customer Experience Pages**: Configuration menu entry where you set up the rescheduling button.
* **Reschedule a Delivery**: Toggle in the **Before the Delivery** menu item that activates the **reschedule** button in customer email communications.
* **Disable Before Delivery**: Option that sets the rescheduling link validity.
* **Configure Outgoing Messages** > **Email Templates**: Where you add the email template that carries the rescheduling link.
* **Time window to communicate**: Template type you click when adding an email template.
* **Outgoing Emails**: Setting you enable to allow communication with the end customer.

## Set up the rescheduling button

1. Launch the Nomadia Delivery application and go to the **Configuration** tab.

![](<../.gitbook/assets/image-26 (4).png>)

2. From the drop-down menu, select **Configure Customer Experience Pages.**

![](<../.gitbook/assets/image-27 (4).png>)

3. Click the **Before the Delivery** menu item.
4. Enable the **Reschedule a Delivery** toggle to activate the **reschedule** button in **customer email communications**.

![](<../.gitbook/assets/image-28 (4).png>)

5. Set the rescheduling link validity using the Disable Before Delivery option. You can configure the link to be active from a maximum of 12 hours before delivery to a minimum of 3 hours before delivery, based on your operational requirements.

![](<../.gitbook/assets/image-29 (4).png>)

6. Click **Save** to apply and save the rescheduling configuration.

![](<../.gitbook/assets/image-30 (3).png>)

## Set up the rescheduling link in customer emails

1. Launch the Nomadia Delivery application and go to the **Configuration** tab.

![](<../.gitbook/assets/image-26 (4).png>)

2. From the drop-down menu, select **Configure Outgoing Messages**.

![](<../.gitbook/assets/image-32 (3).png>)

3. Click the **Email Templates** menu item.

![](<../.gitbook/assets/image-33 (3).png>)

4. Click the **Actions** dropdown menu and select **Add**.

![](<../.gitbook/assets/image-34 (3).png>)

5. Click **Time window to communicate**.

![](<../.gitbook/assets/image-35 (3).png>)

6. Enable Outgoing Emails to allow communication with the end customer.

<figure><img src="../.gitbook/assets/Nomadia_Layout_V1 (2) (1).png" alt=""><figcaption></figcaption></figure>

7. When composing the message, use the $ keyword to insert mission-specific links and values.

<figure><img src="../.gitbook/assets/Nomadia_Layout_V1 (3) (1).png" alt=""><figcaption></figcaption></figure>

8. Click **Save**.

<figure><img src="../.gitbook/assets/Nomadia_Layout_V1 (4) (1).png" alt=""><figcaption></figcaption></figure>
