# configuremissionprefilters

The **Configure Managed Machine Pre-Filters** feature creates custom filter rules based on machine status and type in **Nomadia Delivery**. You need this feature to control fleet visibility and focus workflows on specific operational tasks. By configuring pre-filters, you will streamline tracking and optimize machine management across your team.

### Getting Started

Prerequisites and requirements:
- Access to **Nomadia Delivery** with administrative or dispatcher access.
- Active machine records configured in the system.
- Web browser connected to the SaaS platform.

Initial setup steps:
1. Navigate to **Configuration** in the main menu.

![Flow 0:06 to 0:22](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_06_to_0_to_22.gif "Configuration Menu – Opening the main Configuration settings menu.")

2. Select **Machine Pre-Filters** from the settings list.

![Frame at 0:22](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_22.png "Machine Pre-Filters Screen – Viewing the Machine Pre-Filters page.")

3. Click **Actions** and select **Add** to open the filter configuration builder.

![Flow 0:06 to 0:22](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_06_to_0_to_22.gif "Actions Menu – Selecting Actions and clicking Add to create a filter.")

### Feature Overview

- **Status Field**: Selects specific machine operational statuses for the query. It filters the fleet view to show relevant machine states.

![Frame at 0:28](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_28.png "Status Field – Selecting operational machine status filter options.")

- **Machine Type Field**: Specifies machine categories included in the filter. It restricts query results to designated machine types.

![Frame at 0:38](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_38.png "Machine Type Field – Choosing machine types for query filtering.")

- **Logic Operator (AND/OR)**: Toggles conditional logic between filter rules. It defines whether all or any conditions must match.

![Flow 0:50 to 0:56](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_50_to_0_to_56.gif "Logic Operator – Toggling AND or OR conditions between filter rules.")

- **Group Condition**: Combines multiple filter statements into a logical group. It allows complex nested filtering logic.

![Flow 1:24 to 1:34](configuremissionprefilters-configuremissionprefilters_timestamp_1_to_24_to_1_to_34.gif "Group Condition – Grouping multiple conditions into logical units.")

- **Query Name Field**: Accepts a custom text label for the filter query. It helps users identify saved filter configurations easily.

![Frame at 1:34](configuremissionprefilters-configuremissionprefilters_timestamp_1_to_34.png "Query Name Field – Inputting a unique name for the filter query.")

- **Translation Plus Symbol**: Opens translation entry fields for additional languages. It enables multi-language support for regional dispatchers.

![Flow 2:04 to 2:12](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_04_to_2_to_12.gif "Translation Plus Symbol – Clicking the plus icon to add a translation language.")

- **Delete Language Button**: Removes an added language translation entry. It deletes unneeded language fields from the query.

![Flow 2:34 to 2:44](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_34_to_2_to_44.gif "Delete Language Button – Clicking delete to remove a translation field.")

- **Save Button**: Stores the configured filter rules and query name. It updates system records with your filter configuration.

![Frame at 2:44](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_44.png "Save Button – Saving the pre-filter query configuration.")

- **Manage Usage Option**: Opens user access assignment settings for pre-filters. It controls which users receive restricted machine views.

![Flow 2:54 to 3:02](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_54_to_3_to_02.gif "Manage Usage Option – Accessing user management for filter assignment.")

- **Apply Button**: Executes active filter parameters on the machine list. It refreshes the display to show matching fleet records.

![Frame at 3:58](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_58.png "Apply Button – Applying selected pre-filters to the machine list view.")

### How To: Create and Customize a Machine Pre-Filter

1. Open **Configuration** and click **Machine Pre-Filters**.

![Flow 0:06 to 0:22](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_06_to_0_to_22.gif "Configuration Menu – Accessing Machine Pre-Filters settings.")

2. Click **Actions** and select **Add** to launch the editor.

![Flow 0:06 to 0:22](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_06_to_0_to_22.gif "Actions Menu – Clicking Add under Actions to build a pre-filter.")

3. Choose required status values from the **Status Field**.

![Frame at 0:28](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_28.png "Status Selection – Choosing machine status values.")

4. Choose required machine categories from the **Machine Type Field**.

![Frame at 0:38](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_38.png "Machine Type Selection – Choosing machine type values.")

5. Click to add additional status conditions if needed.

![Frame at 0:46](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_46.png "Additional Status – Adding extra status condition rules.")

6. Select **AND** or **OR** logic to connect your conditions.

![Flow 0:50 to 0:56](configuremissionprefilters-configuremissionprefilters_timestamp_0_to_50_to_0_to_56.gif "Logical Operator – Selecting AND or OR condition logic.")

7. Group conditions together if combining multiple filter rules.

![Flow 1:24 to 1:34](configuremissionprefilters-configuremissionprefilters_timestamp_1_to_24_to_1_to_34.gif "Group Conditions – Grouping filter rules into a unified block.")

8. Type a clear descriptive label in the **Query Name Field**.

![Frame at 1:34](configuremissionprefilters-configuremissionprefilters_timestamp_1_to_34.png "Query Name – Naming the custom filter query.")

9. Click **Save** to create the filter query.

![Frame at 2:44](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_44.png "Save Query – Clicking Save to complete pre-filter creation.")

### How To: Add Translations to a Pre-Filter Query

1. Click the **Translation Plus Symbol** next to the translation field.

![Flow 2:04 to 2:12](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_04_to_2_to_12.gif "Translation Field – Clicking the plus symbol to add a language.")

2. Select your target language from the dropdown list.

![Frame at 2:12](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_12.png "Language Selection – Choosing language from dropdown menu.")

3. Enter the query name in the selected language.

![Flow 2:24 to 2:32](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_24_to_2_to_32.gif "Translated Name – Typing the query name in another language.")

4. Click the **Delete Language Button** if you want to remove a language.

![Flow 2:34 to 2:44](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_34_to_2_to_44.gif "Delete Language – Clicking delete to remove language field.")

5. Click **Save** to update language translations.

![Frame at 2:44](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_44.png "Save Translation – Saving multi-language query settings.")

### How To: Assign a Pre-Filter Query to a User

1. Navigate to **Configuration** and click **Manage Usage**.

![Flow 2:54 to 3:02](configuremissionprefilters-configuremissionprefilters_timestamp_2_to_54_to_3_to_02.gif "Manage Usage – Opening Manage Usage configuration page.")

2. Select the target user email address.

![Flow 3:02 to 3:18](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_02_to_3_to_18.gif "User Selection – Choosing user email from assignment list.")

3. Locate the **Machine Pre-Filters** section.

![Frame at 3:18](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_18.png "Machine Pre-Filters Section – Viewing user assignment fields.")

4. Select the query name to assign, such as **Out for Delivery**.

![Flow 3:26 to 3:30](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_26_to_3_to_30.gif "Assign Query – Selecting Out for Delivery filter for user.")

5. Click **Save** to apply the assignment.

![Frame at 3:30](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_30.png "Save Assignment – Saving user filter assignment.")

6. Navigate to **Machines** in the main menu.

![Frame at 3:40](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_40.png "Machines Screen – Accessing fleet machines page.")

7. Click **Apply** to view assigned status machines only.

![Flow 3:56 to 4:02](configuremissionprefilters-configuremissionprefilters_timestamp_3_to_56_to_4_to_02.gif "Apply Filter – Filtering view to show assigned machines.")

### How To: Remove an Assigned Pre-Filter from a User

1. Go to **Configuration** and select **Manage Usage**.

![Flow 4:02 to 4:14](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_02_to_4_to_14.gif "Manage Usage Navigation – Opening Manage Usage page.")

2. Click the user email address.

![Frame at 4:14](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_14.png "User Profile – Selecting user email address.")

3. Clear the assigned query under **Machine Pre-Filters**.

![Flow 4:20 to 4:30](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_20_to_4_to_30.gif "Remove Filter Assignment – Unchecking pre-filter for user.")

4. Click **Save** to update user profile settings.

![Frame at 4:30](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_30.png "Save Unassignment – Saving updated user profile.")

5. Navigate to **Machines** and clear active filter selections.

![Flow 4:34 to 4:54](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_34_to_4_to_54.gif "Clear Machine Filters – Removing active status filters on Machines page.")

6. Click **Apply** to view all fleet machines again.

![Flow 4:54 to 4:58](configuremissionprefilters-configuremissionprefilters_timestamp_4_to_54_to_4_to_58.gif "Apply All Fleet – Restoring full machine fleet view.")

### Productivity Tips

- 💡 **Restricted Operational Focus**: Assigning specific pre-filters under Manage Usage narrows team member views to critical operational statuses like Out for Delivery.
- 💡 **Multi-Language Adaptability**: Adding language translations ensures international team members view filter query titles in their preferred language.
- ⚠️ **Hidden Fleet Visibility**: Leaving a pre-filter assigned under Manage Usage prevents dispatchers from viewing the full fleet until the assignment is removed.
