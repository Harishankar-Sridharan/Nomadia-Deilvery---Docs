# Coloring and Filter

Use the **Coloring** and **Filter** options to organize and display data according to specific conditions.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the contractor address list.
* Decide which conditions you want to use to organize and display the addresses.

## Feature overview

* **Coloring**: Opens a popup where you apply conditions to display addresses with custom colors.
* **Filter**: Organizes and displays data according to specific conditions.

## Color and filter the address list

1. Use the **Coloring** and **Filter** options to organize and display data according to specific conditions.
