# Contractors

Use the topics below to register contractors, create contractor users, and manage their addresses, restrictions, and plans in Nomadia Delivery.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Contractors** module.
* Register a contractor first, because contractors must be registered by the transporter before they can upload mission data.

## Feature overview

* **Register a Contractor**: Add a contractor from the **Contractors** module so that it can upload mission data.
* **Create a Contractor User**: Create contractor access from the configuration section so the contractor can use the system.
* **Manage Address List**: Create an address list that serves as a master record of customer information.
* **Customize the Address Visibility**: Control which information is visible or editable in global and contractor address lists.
* **Coloring and Filter**: Organize and display address data according to specific conditions.
* **Contractor Restrictions**: Control access to templates and mission editing permissions.
* **Fixed and Recurring Plans**: Create plans that support contractors with long-term delivery and pick-up commitments.
* **Reception Management**: Manage, verify, and track container deliveries from the field.
