# A Configuration User Type

Nomadia Delivery is introducing a new user type called Contractor. This user type can import missions, manage address lists, and track mission progress, providing contractors with greater control over their work and enhancing overall efficiency.

## Create a contractor user

1. Open the Nomadia Delivery application and go to **Configuration** > **Manage Users**.

![](<../.gitbook/assets/image-7 (4).png>)

2. Click the **Action** button and select **Add**.

![](<../.gitbook/assets/image-8 (3).png>)

3. Click **OK** to create a new user. Alternatively, you can create a user based on an existing one, which speeds up the process by copying all settings from the existing user to the new profile.

![](<../.gitbook/assets/image-9 (3).png>)

4. In the **Generalities** tab, enter the login and last name of the user and enable the user status.
5. Go to the **Access** tab.

![](<../.gitbook/assets/image-10 (2).png>)

6. Enable web access for the user and select the contractor's website from the drop-down menu.

![](<../.gitbook/assets/image-11 (2).png>)

7. Select the appropriate contractor (created in the previous section of this document) to link with the user.
8. Go to the **Roles & Rights** tab.

![](<../.gitbook/assets/image-12 (2).png>)

9. Assign the necessary rights to the new Contractor user.
10. Go to the **Agencies** tab.

![](<../.gitbook/assets/image-13 (2).png>)

11. Click **Save**.

![](<../.gitbook/assets/image-14 (2).png>)

## Activate the contractor account

The contractor receives an email with instructions to set a password and activate the account.

1. Click the link in the email to verify the account.

![](../.gitbook/assets/image-5.png)

2. Enter the verification code received by email and click **Verify Code**.

![](<../.gitbook/assets/image-16 (2).png>)

3. Click **Continue**.

![](<../.gitbook/assets/image-17 (2).png>)

4. Enter and confirm the new password, then click **Continue**.

![](<../.gitbook/assets/image-18 (2).png>)

5. Review and accept the End User License Agreement (EULA), then click **Continue**.

![](<../.gitbook/assets/image-19 (2).png>)

### Result

The new Contractor user can now access the application and begin performing tasks.

![](<../.gitbook/assets/image-20 (2).png>)

## Tips

{% hint style="info" %}
**Missing contractor**: If no contractor appears in the list, ensure that one has been created in the Contractors module.
{% endhint %}
