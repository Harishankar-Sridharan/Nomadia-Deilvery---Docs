# Registration

In the Nomadia Delivery application, contractors must be registered by the transporter before they can upload mission data. To register a contractor, the transporter must add a contractor from the **Contractors** module. Once the contractor is registered, the transporter can create contractor access from the configuration section/module. This allows the contractor to access the system and perform their tasks.

## Before you begin

* Sign in to **Nomadia Delivery** as the transporter with a user profile that has access to the **Contractors** module.
* Have the identifier and name of the contractor available, because they are mandatory fields.
* For a bulk import, prepare an Excel file with the contractors.

## Feature overview

* **Identifier and name**: Mandatory fields when you register a contractor.
* **Additional details**: Optional information such as the contractor's address, region, and status configuration types.
* **Map**: Displays the geographical location that corresponds to the contractor's address.
* **Bulk import**: Adds multiple contractors at once from an Excel file.

## Register a contractor

1. Open the Nomadia Delivery application and navigate to **Contractors**.
2. Click **Missions**.

![](<../.gitbook/assets/image-1 (4).png>)

3. Click the **Actions** menu and click the **Add** button.

![](<../.gitbook/assets/image-2 (4).png>)

4. Enter the identifier and name, which are mandatory fields. The transporter can also provide additional details, such as the contractor's address, region, and status configuration types.
5. Enter the contractor's address. The map displays the corresponding geographical location.

![](<../.gitbook/assets/image-3 (4).png>)

6. Click **Save** to register the contractor in the delivery management system.

![](<../.gitbook/assets/image-4 (4).png>)

### Result

The new contractor is successfully added.

![](<../.gitbook/assets/image-5 (4).png>)

## Import contractors in bulk

Alternatively, contractors can be bulk imported using an Excel file, which helps save time and effort when adding multiple contractors simultaneously.
