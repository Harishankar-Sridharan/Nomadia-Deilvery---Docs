# Color-code custom fields

Color coding custom fields visually highlights key data based on the value ranges in **Nomadia Delivery**. Use this feature to quickly spot critical operational metrics and make faster decisions. Set up custom rules to automatically color-code values across your system workflows.

#### Getting started

Prerequisites:

* Active account in **Nomadia Delivery** with administrative access.
* Pre-existing custom field parameters configured in the system.

Initial Setup Steps:

1. Log into **Nomadia Delivery**, navigate to **Configuration**, and select **Custom Field**.

![Log into Nomadia Delivery, navigate to Configuration, and select Custom Field](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_08_to_0_to_15.gif)

#### Feature overview

* **Configuration**: Accesses administrative system settings to locate custom parameters.
* **Custom Field**: Opens the management list for custom fields across the system.
* **Package Value**: Represents the specific numerical custom field attribute assigned to assets.
* **Edit Button**: Opens configuration options for the selected custom field attribute.
* **Conditional Background Color**: Defines numerical threshold ranges and their corresponding background colors.
* **Search Button**: Filters mission records by mission number to verify attribute colors.

#### Configure color coding rules

1. Log into **Nomadia Delivery** and click **Configuration**.

![Log into Nomadia Delivery and click Configuration](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_08_to_0_to_15.gif)

2. Click **Custom Field** from the configuration menu.

![Click Custom Field from the configuration menu](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_15.png)

3. Locate the target field and click the **Edit** button next to **Package Value**.

![Locate the target field and click the Edit button next to Package Value](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_15_to_0_to_21.gif)

4. Scroll down to **Conditional Background Color**.

![Scroll down to Conditional Background Color](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_21_to_0_to_23.gif)

5. Input numerical value ranges and assign background colors.

![Input numerical value ranges and assign background colors](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_23_to_0_to_44.gif)

6. Click **Save** to apply the color rules.

![Click Save to apply the color rules](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_54.png)

#### Verify color coding in mission entry

1. Click **Mission** from the main navigation menu.
2. Click **Add** to create a new mission entry.

![Click Add to create a new mission entry](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_09_to_1_to_14.gif)

3. Select the **Mission Type** and **Agency**, then click **Next**.

![Select the Mission Type and Agency, then click Next](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_15_to_1_to_20.gif)

4. Enter a numerical value in **Package Value** to trigger conditional color highlighting.

![Enter a numerical value in Package Value to trigger conditional color](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_22_to_1_to_32.gif)

5. Click **Add** to complete saving the Mission entry.

![Click Add to complete saving the Mission entry](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_32_to_1_to_34.gif)

#### Verify color coding in mission table

1. Navigate back to the main overview screen.
2. Locate the **Mission Table** view on the screen.

![Locate the Mission Table view on the screen](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_53.png)

3. Review the **Package Value** column to confirm automatic background coloring.

![Review the Package Value column to confirm automatic background coloring](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_59.png)

#### Verify color coding via mission search

1. Click the **Search** button in the top interface.

![Click the Search button in the top interface](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_2_to_08.png)

2. Search for the target mission using the **Mission Number**.

![Search for the target mission using the Mission Number](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_2_to_11_to_2_to_15.gif)

3. Scroll right across the search table using the horizontal scroll bar.

![Scroll right across the search table using the horizontal scroll bar](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_2_to_17_to_2_to_20.gif)

4. Verify the visual color highlighting applied under the **Package Value** header.

![Verify the visual color highlighting applied under the Package Value header](.gitbook/assets/colorcodingthecustomfields-colorcodingthecustomfields_timestamp_2_to_26.png)

***

#### Productivity tips

**Multi-Location Verification**: Verify custom field color coding across mission creation, systems tables, and search views.
{% endhint %}

**Horizontal Scroll Access**: Use the horizontal scroll bar in search tables to locate hidden package value colors.
{% endhint %}

{% endhint %}
