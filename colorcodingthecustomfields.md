# colorcodingthecustomfields

Color coding custom fields visually highlights key data based on value ranges in **Nomadia Delivery**. Use this feature to quickly spot critical operational metrics and make faster decisions. Set up custom rules to automatically color-code values across your system workflows.

---

### Getting Started

Prerequisites:
- Active account in **Nomadia Delivery** with administrative access.
- Pre-existing custom field parameters configured in the system.

Initial Setup Steps:
1. Log into **Nomadia Delivery**, navigate to **Configuration**, and select **Custom Field**.

![Flow 0:08 to 0:15](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_08_to_0_to_15.gif "Configuration Menu – Navigate to custom field settings.")

2. Select a value and click the **Edit** button next to **Practice Value**.

![Flow 0:15 to 0:21](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_15_to_0_to_21.gif "Practice Value Field – Click Edit to adjust settings.")

3. Scroll down to the **Conditional Background Color** section.

![Flow 0:21 to 0:23](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_21_to_0_to_23.gif "Conditional Background Color Section – Scroll to locate color settings.")

4. Configure value ranges and select color assignments for each range.

![Flow 0:23 to 0:44](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_23_to_0_to_44.gif "Color Range Settings – Define value thresholds and background colors.")

5. Click the **Save** button to store your configuration.

![Frame at 0:54](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_54.png "Save Button – Save custom field color coding rules.")

### How To: Configure Color Coding Rules

1. Log into **Nomadia Delivery** and click **Configuration**.

![Flow 0:08 to 0:15](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_08_to_0_to_15.gif "Configuration Menu – Navigate to custom field options.")

2. Click **Custom Field** from the configuration menu.

![Frame at 0:15](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_15.png "Custom Field Panel – List of available custom fields.")

3. Locate the target field and click the **Edit** button next to **Practice Value**.

![Flow 0:15 to 0:21](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_15_to_0_to_21.gif "Practice Value Row – Click edit button.")

4. Scroll down to **Conditional Background Color**.

![Flow 0:21 to 0:23](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_21_to_0_to_23.gif "Conditional Background Color Section – View threshold color options.")

5. Input numerical value ranges and assign background colors.

![Flow 0:23 to 0:44](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_23_to_0_to_44.gif "Value Range Inputs – Set color thresholds.")

6. Click **Save** to apply the color rules.

![Frame at 0:54](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_0_to_54.png "Save Action – Save configuration.")

### How To: Verify Color Coding in Machine Entry

1. Click **Machine** from the main navigation menu.

![Frame at 1:04](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_04.png "Machine Menu – Open machine management interface.")

2. Click **Add** to create a new machine entry.

![Flow 1:09 to 1:14](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_09_to_1_to_14.gif "Add Machine Button – Initiate machine creation flow.")

3. Select the **Machine Type** and **Agency**, then click **Next**.

![Flow 1:15 to 1:20](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_15_to_1_to_20.gif "Machine Setup Form – Enter type and agency details.")

4. Enter a numerical value in **Practice Value** to trigger conditional color highlighting.

![Flow 1:22 to 1:32](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_22_to_1_to_32.gif "Practice Value Input – Entered value triggers color coding.")

5. Click **Add** to complete saving the machine entry.

![Flow 1:32 to 1:34](colorcodingthecustomfields-colorcodingthecustomfields_timestamp_1_to_32_to_1_to_34.gif "Add Button – Complete machine entry.")

### Productivity Tips

- 💡 **Multi-Location Verification**: Verify custom field color coding across machine creation, systems tables, and search views.
- 💡 **Horizontal Scroll Access**: Use the horizontal scroll bar in search tables to locate hidden practice value colors.
- ⚠️ **Unsaved Configuration Rules**: Click Save after editing color ranges or your custom background rules will not apply.
