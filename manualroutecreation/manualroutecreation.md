# manualroutecreation

Manual route creation in **Nomadia Delivery** allows dispatchers to build and assign custom delivery routes. Use this feature to set schedule dates, assign deliverers, and define route endpoints manually. By creating routes manually, you maintain precise control over transport operations.

### Getting Started

Prerequisites:
- Active account in **Nomadia Delivery**.
- Access permissions for machine and route management.

Initial setup steps:
1. Open the machine management dashboard.

2. Select the target **Machine** from the list.

![Frame at 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_20.png "Machine – Selected machine item requiring route assignment.")

3. Click **Actions** to view available options.

![Frame at 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_20.png "Actions – Dropdown menu opening for machine management.")

4. Select **Assign** to launch manual route creation.

![Flow 0:09 to 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_09_to_0_to_20.gif "Assign – Opening the route assignment form.")

### Feature Overview

- **Machine**: Selected machine item designated for route assignment.

- **Deliverer**: Selection dropdown to assign a specific driver.

![Frame at 1:08](manualroutecreation-manualroutecreation_timestamp_1_to_08.png "Deliverer – Assigns drivers to the created route.")

### How To: Create and Assign a Route Manually

1. Select the target **Machine** from the list.

![Frame at 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_20.png "Machine – Selecting the machine item.")

2. Click **Actions**.

![Frame at 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_20.png "Actions – Opening machine actions menu.")

3. Click **Assign**.

![Flow 0:09 to 0:20](manualroutecreation-manualroutecreation_timestamp_0_to_09_to_0_to_20.gif "Assign – Displaying route assignment window.")

4. Click the **Calendar Icon**.

![Frame at 0:25](manualroutecreation-manualroutecreation_timestamp_0_to_25.png "Calendar Icon – Opening calendar tool.")

5. Select any date for the route.

![Flow 0:25 to 0:29](manualroutecreation-manualroutecreation_timestamp_0_to_25_to_0_to_29.gif "Calendar Icon – Selecting target date.")

6. Tap the **Route Field**.

![Frame at 0:29](manualroutecreation-manualroutecreation_timestamp_0_to_29.png "Route Field – Tapping route selection box.")

7. Choose to create a new route or select an existing route.

![Flow 0:37 to 0:41](manualroutecreation-manualroutecreation_timestamp_0_to_37_to_0_to_41.gif "Route Field – Choosing route option.")

8. Enter the route name in the **Route Name Field**.

![Frame at 0:46](manualroutecreation-manualroutecreation_timestamp_0_to_46.png "Route Name Field – Entering route name.")

9. Tap the **Clock Icon** to select the time.

![Flow 0:46 to 0:57](manualroutecreation-manualroutecreation_timestamp_0_to_46_to_0_to_57.gif "Clock Icon – Choosing scheduled time.")

10. Select the **Deliverer** to assign to the route.

![Flow 0:57 to 1:08](manualroutecreation-manualroutecreation_timestamp_0_to_57_to_1_to_08.gif "Deliverer – Assigning driver.")

11. Select the **Start Point** and **End Point**.

![Flow 1:08 to 1:23](manualroutecreation-manualroutecreation_timestamp_1_to_08_to_1_to_23.gif "Start Point and End Point – Defining start and end locations.")

12. Enable **Automatically Order Machines** if needed.

![Flow 1:23 to 1:32](manualroutecreation-manualroutecreation_timestamp_1_to_23_to_1_to_32.gif "Automatically Order Machines – Toggling automatic machine sequence.")

13. Select **Ignore** or **Replace** for conflict handling.

![Flow 1:32 to 1:36](manualroutecreation-manualroutecreation_timestamp_1_to_32_to_1_to_36.gif "Ignore or Replace – Setting conflict preferences.")

14. Click **Force Assignment** to finalize the route assignment.

![Flow 1:36 to 1:47](manualroutecreation-manualroutecreation_timestamp_1_to_36_to_1_to_47.gif "Force Assignment – Finalizing assignment.")

### Productivity Tips

- 💡 **Automatic Machine Ordering**: Enable automatic machine ordering to sequence machines along the route automatically.
- ⚠️ **Conflict Handling Settings**: Select whether to ignore or replace conflicts before clicking **Force Assignment** to avoid unexpected route overwrites.
