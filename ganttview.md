# ganttview

The **Gantt view** displays complete route information within Nomadia Delivery. Access this feature to manage driver schedules and monitor active deliveries efficiently. Use this interface to inspect route progress and view assigned delivery paths.

### Getting Started

Prerequisites:
- Active user account for **Nomadia Delivery**.
- System permissions to access the **Machines** section.

Initial setup steps:
1. Log into **Nomadia Delivery**.

![Flow 0:00 to 0:09](ganttview-ganttview_timestamp_0_to_00_to_0_to_09.gif "Nomadia Delivery Login – User logs into Nomadia Delivery account.")

2. Navigate to the **Machines** section.

![Flow 0:09 to 0:16](ganttview-ganttview_timestamp_0_to_09_to_0_to_16.gif "Machines Navigation – User selects the Machines menu item.")

3. Scroll down to locate the **Route** section.

![Frame at 0:17](ganttview-ganttview_timestamp_0_to_17.png "Route Section – Route management section becomes visible on screen.")

### Feature Overview

- **Route Selector**: Allows selection of a specific route to execute management actions.

![Frame at 0:31](ganttview-ganttview_timestamp_0_to_31.png "Route Selector – Route is highlighted for action execution.")

- **Eye Icon**: Opens the map view to display the selected route geographically.

![Flow 0:31 to 0:43](ganttview-ganttview_timestamp_0_to_31_to_0_to_43.gif "Eye Icon – User clicks the eye icon to show the route map.")

- **Edit Icon**: Opens the route editor to modify existing route settings.

![Flow 0:43 to 0:52](ganttview-ganttview_timestamp_0_to_43_to_0_to_52.gif "Edit Icon – User clicks the edit icon to modify the route.")

- **Publish Symbol**: Indicates that the selected route is published.

![Frame at 1:06](ganttview-ganttview_timestamp_1_to_06.png "Publish Symbol – Icon displays to confirm published route status.")

- **Block Symbol**: Displays alongside the publish symbol when a published route is blocked.

![Frame at 1:12](ganttview-ganttview_timestamp_1_to_12.png "Block Symbol – Icon shows next to the publish symbol when blocked.")

- **Green Button Symbol**: Displays as a green button when a route is granted.

![Frame at 1:26](ganttview-ganttview_timestamp_1_to_26.png "Green Button Symbol – Green button appears confirming granted route status.")

- **Route Name**: Displays the designated name of the route.

![Frame at 1:28](ganttview-ganttview_timestamp_1_to_28.png "Route Name – Text label displaying the assigned route name.")

- **Route Date**: Displays the scheduled date for route execution.

![Frame at 1:35](ganttview-ganttview_timestamp_1_to_35.png "Route Date – Scheduled execution date assigned to the route.")

- **Deliverer Name**: Displays the name of the deliverer assigned to the route.

![Frame at 1:38](ganttview-ganttview_timestamp_1_to_38.png "Deliverer Name – Label showing the assigned deliverer.")

- **Start and End Time**: Shows the scheduled start time and end time for the route.

![Frame at 1:47](ganttview-ganttview_timestamp_1_to_47.png "Start and End Time – Schedule bounds displaying start and finish times.")

- **Route Type**: Identifies the specific classification type of the route.

![Frame at 1:47](ganttview-ganttview_timestamp_1_to_47.png "Route Type – Label indicating the operational route classification.")

- **Back Button**: Returns the view to the main route list.

![Flow 2:04 to 2:09](ganttview-ganttview_timestamp_2_to_04_to_2_to_09.gif "Back Button – User clicks back button to return to route list.")

### How To: View a Route on the Map

1. Select the desired route from the **Route** list.

![Frame at 0:31](ganttview-ganttview_timestamp_0_to_31.png "Route Selection – Selected route is highlighted in the list.")

2. Click the **Eye Icon** next to the route.

![Flow 0:31 to 0:43](ganttview-ganttview_timestamp_0_to_31_to_0_to_43.gif "Eye Icon Click – User clicks the Eye Icon to load the map view.")

3. View the full route layout on the map.

![Frame at 0:43](ganttview-ganttview_timestamp_0_to_43.png "Route Map View – Map displays the visual route path.")

### How To: Edit a Route

1. Select the target route in the **Route** section.

![Frame at 0:31](ganttview-ganttview_timestamp_0_to_31.png "Route Selection – Target route is selected for modification.")

2. Click the **Edit Icon**.

![Flow 0:43 to 0:52](ganttview-ganttview_timestamp_0_to_43_to_0_to_52.gif "Edit Icon Click – User clicks the Edit Icon to open route editor.")

3. Modify the necessary route details.

### How To: Inspect Route Details

1. Click on the specific route entry.

![Flow 1:48 to 1:54](ganttview-ganttview_timestamp_1_to_48_to_1_to_54.gif "Route Click – User clicks a route entry to view detailed metrics.")

2. Review event status, duration, start time, end time, drive duration, total distance, building, and floor details.

![Frame at 2:03](ganttview-ganttview_timestamp_2_to_03.png "Route Details View – Full list of route metrics displayed on screen.")

3. Click the **Back Button** to return to the route list.

![Flow 2:04 to 2:09](ganttview-ganttview_timestamp_2_to_04_to_2_to_09.gif "Back Button Click – User clicks back button to exit detail screen.")

### Productivity Tips

- 💡 **Granted Route Identification**: Look for the green button symbol to instantly verify that a route has been granted.
- ⚠️ **Blocked Route Warning**: Avoid dispatching routes that display a block symbol alongside the publish symbol.
