# declaringaparcelforacontainermission

The parcel declaration feature allows dispatchers to define and assign parcel dimensions and container structures to container machines in Nomadia Delivery. This ensures accurate capacity planning and seamless logistics execution during container missions. Users can declare parcels when adding a new machine, editing an existing container, or directly from the action panel.

### Getting Started

Prerequisites and requirements:
- Access to the **Machine** module in Nomadia Delivery.
- An active container machine configuration.
- Parcel dimensions including length, width, height, and weight.

Setup steps:
1. Navigate to the **Machine** menu.

![Flow 0:00 to 0:07](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_00_to_0_to_07.gif "Machine Menu – Navigating to the machine management interface.")

2. Click on **Actions** to open machine settings.

![Flow 0:07 to 0:12](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_07_to_0_to_12.gif "Actions Menu – Opening the actions dropdown for machine configuration.")

- **Actions Menu**: Displays machine configuration tools including machine creation and parcel declaration.

![Frame at 0:12](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_12.png "Actions Menu – Displays options to add a machine or declare parcels.")

![Frame at 0:23](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_23.png "Add Button – Opens the machine setup form.")

- **Agency Field**: Sets the managing organizational unit for the machine.

![Frame at 0:30](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_30.png "Agency Field – Dropdown menu to select the operating agency.")

- **Machine Type Field**: Specifies the category and operational model of the container machine.

![Frame at 0:30](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_30.png "Machine Type Field – Selector for defining machine specifications.")

- **Container Type Selector**: Sets the container format for parcel generation.

![Frame at 0:42](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_42.png "Container Type Selector – Menu for choosing container types.")

- **Address Field**: Assigns the operational location for the container machine.

![Frame at 0:47](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_47.png "Address Field – Input area for specifying machine location.")

- **Parcel Section**: Collects length, width, height, and weight values for declared parcels.

![Frame at 1:26](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_26.png "Parcel Section – Form fields for physical dimensions and weight.")

![Frame at 1:35](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_35.png "Parcel Size Section – Selector for setting the parcel count.")

![Frame at 3:11](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_11.png "Declare Parcel Option – Action item to add extra parcels.")

### How To: Declare a Parcel While Adding a Machine

1. Open the **Machine** menu.

![Flow 0:07 to 0:12](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_07_to_0_to_12.gif "Machine Menu – Opening machine settings from actions.")

2. Click on **Add**.

![Flow 0:12 to 0:23](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_12_to_0_to_23.gif "Add Button – Launching the machine setup workflow.")

3. Select the **Agency** and **Machine Type**.

![Flow 0:23 to 0:30](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_23_to_0_to_30.gif "Agency and Machine Type – Selecting agency and machine options.")

4. Click on **Next**.

![Flow 0:30 to 0:35](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_30_to_0_to_35.gif "Next Button – Moving to container details step.")

5. Select the **Container Type**.

![Flow 0:35 to 0:42](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_35_to_0_to_42.gif "Container Type – Setting container configuration.")

6. Select the **Address**.

![Flow 0:42 to 0:47](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_0_to_42_to_0_to_47.gif "Address Selection – Choosing machine location.")

7. Select the required **Custom Fields**.

![Flow 1:01 to 1:10](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_01_to_1_to_10.gif "Custom Fields – Completing customized parameters.")

8. Enter length, width, height, and weight in the **Parcel Section**.

![Flow 1:10 to 1:26](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_10_to_1_to_26.gif "Parcel Section – Filling parcel dimensions and weight.")

9. Select the total number of parcels to create in the **Parcel Size Section**.

![Flow 1:26 to 1:35](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_26_to_1_to_35.gif "Parcel Size Section – Entering number of parcels.")

10. Click on **Create**.

![Flow 1:35 to 1:43](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_35_to_1_to_43.gif "Create Button – Submitting initial parcel parameters.")

11. Click on **Add** to finish creating the parent and child containers.

![Flow 1:48 to 1:51](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_1_to_48_to_1_to_51.gif "Add Button – Completing creation of parent and child containers.")

![Flow 2:21 to 2:27](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_2_to_21_to_2_to_27.gif "Parcel Quantity – Adjusting quantity of parcels.")

4. Click on **Create**.

![Flow 2:27 to 2:38](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_2_to_27_to_2_to_38.gif "Create Button – Generating additional container structures.")

![Flow 2:38 to 2:46](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_2_to_38_to_2_to_46.gif "Validate Button – Confirming container addition.")

### How To: Declare a Parcel from the Action Panel

1. Select the parent container and machine, then click on **Actions**.

![Flow 3:01 to 3:07](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_01_to_3_to_07.gif "Actions Menu – Opening options for selected machine.")

2. Click on **Declare Parcel**.

![Flow 3:11 to 3:17](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_11_to_3_to_17.gif "Declare Parcel Option – Selecting parcel declaration action.")

3. Choose the **Container Type**.

![Flow 3:17 to 3:24](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_17_to_3_to_24.gif "Container Type – Selecting container category.")

4. Click to add a parcel.

![Flow 3:24 to 3:29](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_24_to_3_to_29.gif "Add Parcel – Adding extra parcel entry.")

5. Click on **Validate** to confirm.

![Flow 3:29 to 3:37](declaringaparcelforacontainermission-declaringaparcelforacontainermission_timestamp_3_to_29_to_3_to_37.gif "Validate Button – Saving parcel declaration.")

### Productivity Tips

- 💡 **Parent and Child Structure**: Generating multiple parcels automatically links child containers to one parent container for simplified mission organization.
- 💡 **Action Panel Convenience**: Add extra parcels directly from the action panel without re-entering the machine creation workflow.
