# customizethestatushierarchy

This feature allows dispatchers to manage how status changes on child machines affect parent containers. It ensures accurate real-time tracking across your logistics operations. Customize status priorities easily to streamline container state synchronization.

### Getting Started

Before you begin, ensure you meet the following prerequisites:
* Create a parent container in the system.
* Create a child container.

Follow these initial setup steps:

1. Navigate to the **Configuration** menu.

![Frame at 0:14](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_14.png "Configuration Screen – Navigating to configuration settings.")

2. Select **Container types** (also referred to as container size).

![Frame at 0:14](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_14.png "Container Types – Selecting the correct container category.")

3. Scroll down to select the correct **Identifier name** (or identified name).

![Frame at 0:30](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_30.png "Identifier Name – Selecting the correct identifier name.")

4. Locate the **Fetch status from side missions** (or fetch status from side machines) option in the bottom right corner.

![Frame at 0:36](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_36.png "Fetch Status – Checking the option to fetch status from side missions.")

5. Check if the option is enabled.

![Frame at 0:39](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_39.png "Fetch Status Option – The option to fetch status from side missions is highlighted.")

6. Click on **Manage status hierarchy** (or manage status identity) once the option is enabled.

![Frame at 0:43](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_43.png "Manage Status Hierarchy Button – Click here to open the status hierarchy settings.")

### Feature Overview

* **Container types**: Selects the container category you want to configure.

![Frame at 0:14](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_14.png "Container Types – Dropdown to select the container configuration.")

* **Identifier name**: Specifies the unique name to identify the container type.

![Frame at 0:30](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_30.png "Identifier Name – Selection field for the correct identifier name.")

* **Fetch status from side missions**: Enables retrieving status updates from child machines.

![Frame at 0:36](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_36.png "Fetch Status from Side Missions – Checkbox in the bottom right corner of the configuration screen.")

* **Manage status hierarchy**: Opens the status prioritizer interface to arrange priorities.

![Frame at 0:43](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_43.png "Manage Status Hierarchy – Access button to configure status priorities.")

### How To: Customize Status Hierarchy

1. Open the status hierarchy configuration window.

![Frame at 0:43](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_43.png "Manage Status Hierarchy Screen – Visualizing already configured status items.")

2. Drag the desired status to the top priority position.

![Flow 0:53 to 1:07](customizethestatushierarchy-customizethestatushierarchy_timestamp_0_to_53_to_1_to_07.gif "Drag Status – Dragging a status to the top priority position in the list.")

3. Click on **Done**.

![Frame at 1:13](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_13.png "Done Button – Clicking Done to confirm status priority order.")

4. Click **Save**.

![Frame at 1:16](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_16.png "Save Button – Saving the new configuration settings.")

5. Go to **Machines**.

![Frame at 1:21](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_21.png "Machines Menu – Navigating to the machines list.")

6. Click any **Child machines** (individual machines connected to the parent container).

![Frame at 1:33](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_33.png "Child Machine Selection – Selecting a child machine from the list.")

7. Change the status.

![Frame at 1:36](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_36.png "Change Status – Selecting a new status for the child machine.")

8. Click on Save.

![Frame at 1:40](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_40.png "Save Machine Status – Saving the updated status for the machine.")

9. Verify that the parent container status changes successfully.

![Frame at 1:47](customizethestatushierarchy-customizethestatushierarchy_timestamp_1_to_47.png "Status Change Verified – Confirming the parent container updated successfully.")

### Productivity Tips

- 💡 **Status Prioritization**: Drag any status to the top of the list to easily set its priority.
- ⚠️ **Enable Fetch Status**: Enable **Fetch status from side missions** first, or the **Manage status hierarchy** option will not be visible.
