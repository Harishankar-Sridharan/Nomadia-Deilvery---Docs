# customizethevalidationofmissionformfields

Customizing mandatory validation enforces required data entries on machine form fields in **Nomadia Delivery**. Dispatchers require mandatory fields to prevent incomplete machine form submissions during daily operations. Configure mandatory fields to ensure accurate field reporting and complete data compliance.

### Getting Started

Administrative requirements and setup steps:

- Administrative access to **Nomadia Delivery** configuration settings.
- Active machine form profile with field identifiers.

Initial setup steps:

1. Select **Configuration** from the main menu.

   ![Flow 0:07 to 0:12](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_07_to_0_to_12.gif "Configuration – Navigation sequence to open system settings.")

2. Click **Custom fields** to manage form fields.

   ![Flow 0:12 to 0:21](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_12_to_0_to_21.gif "Custom fields – Selection of the custom field menu.")

### How To: Configure Mandatory Validation Rules

Configure mandatory validation for machine form fields:

1. Click **Configuration**.

   ![Flow 0:07 to 0:12](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_07_to_0_to_12.gif "Configuration – Navigating to configuration settings.")

2. Click **Custom fields**.

   ![Flow 0:12 to 0:21](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_12_to_0_to_21.gif "Custom fields – Opening custom fields list.")

3. Select any **Identifier**.

   ![Flow 0:21 to 0:27](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_21_to_0_to_27.gif "Identifier – Selecting a field identifier.")

4. Toggle **Mandatory** to enable mandatory field validation.

   ![Flow 0:27 to 0:37](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_27_to_0_to_37.gif "Mandatory – Enabling mandatory validation toggle.")

5. Click **Save**.

   ![Frame at 0:44](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_44.png "Save – Saving mandatory field configuration.")

6. Select **Assign Help** and make it mandatory.

   ![Flow 0:44 to 0:52](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_44_to_0_to_52.gif "Assign Help – Setting mandatory status for assign help.")

7. Click **Save**.

   ![Frame at 0:55](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_55.png "Save – Finalizing validation setup.")

### How To: Apply Validation to Machine Records

Apply mandatory validation rules when editing machine profiles:

1. Navigate to **Machines**.

   ![Flow 0:55 to 1:04](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_0_to_55_to_1_to_04.gif "Machines – Accessing machines section.")

2. Click **Actions**.

   ![Flow 1:04 to 1:06](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_04_to_1_to_06.gif "Actions – Opening actions menu.")

3. Click **Add**.

   ![Flow 1:06 to 1:10](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_10_to_1_to_10.gif "Add – Adding new machine entry.")

4. Click **Agency**.

   ![Flow 1:10 to 1:13](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_10_to_1_to_13.gif "Agency – Selecting agency field.")

5. Click **Next**.

   ![Flow 1:13 to 1:15](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_13_to_1_to_15.gif "Next – Proceeding to next step.")

6. Select **Edit**.

   ![Flow 1:15 to 1:21](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_15_to_1_to_21.gif "Edit – Editing record fields.")

7. Click **Copy**.

   ![Flow 1:21 to 1:23](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_21_to_1_to_23.gif "Copy – Copying field data.")

#### Troubleshooting

Troubleshoot form submission errors:

- **Cannot Save Machine Entry**: Unselected mandatory fields block submission. Select **Assign Help** before saving.

   ![Frame at 1:47](customizethevalidationofmissionformfields-customizethevalidationofmissionformfields_timestamp_1_to_47.png "Save Error – Save blocked due to unselected mandatory field.")

### Productivity Tips

Best practices and operational warnings:

- 💡 **Automatic Mandatory Updates**: Toggle mandatory field validation to update mandatory rules across machine forms instantly.
- ⚠️ **Unselected Mandatory Fields**: Do not leave mandatory fields unselected, or the system prevents saving the machine entry.
