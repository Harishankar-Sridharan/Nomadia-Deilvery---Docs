# Manage User Profile

Organizations with hundreds or thousands of users can take advantage of the User Profiles feature to create multiple profiles with different access rights, simplifying user and permission management.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Configuration** page.
* Know which **Roles** and **Rights** the new profile needs. For details, see [Web - Roles and Rights](web-roles-and-rights.md) and [Mobile - Roles and Rights](mobile-roles-and-rights.md).

## Feature overview

* **Manage User Profiles**: Configuration menu entry where you create user profiles with different access rights.
* **Identifier** and **Profile Name**: Fields that identify the new profile.
* **contractor profiles (Web access)**: Option you enable for contractor users.
* **sub-contractor profiles**: Option you enable for sub-contractor users, for Web or Mobile.
* **Roles** and **Rights**: Settings that define what users with this profile can access.

## Create a user profile

1. Navigate to **Configuration**.

![](<../.gitbook/assets/image-1 (1).png>)

2. Select **Manage User Profiles** from the list.

![](<../.gitbook/assets/image-2 (2).png>)

3. Click the **Actions** drop-down and choose **Add**.

![](<../.gitbook/assets/image-3 (1).png>)

4. Enter the **Identifier** and **Profile Name**.
5. Enable **contractor profiles (Web access)** for contractor users and **sub-contractor profiles** for (Web or Mobile) for sub-contractor users.

![](<../.gitbook/assets/image-4 (2).png>)

6. Enable the required **Roles** and **Rights**.

![](<../.gitbook/assets/image-5 (2).png>)

7. Click **Save**.

![](<../.gitbook/assets/image-6 (2).png>)

### Result

A confirmation message indicates that the user profile has been created successfully.

![](<../.gitbook/assets/image-7 (2).png>)

## Tips

{% hint style="info" %}
**Simplify permission management**: If your organization has hundreds or thousands of users, create multiple profiles with different access rights to simplify user and permission management.
{% endhint %}

{% hint style="info" %}
**Match profiles to user types**: Enable **contractor profiles (Web access)** for contractor users and **sub-contractor profiles** for sub-contractor users.
{% endhint %}
