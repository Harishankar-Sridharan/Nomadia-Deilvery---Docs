# Manage Users

The Manage Users section allows administrators to create, configure, and maintain user accounts in Nomadia Delivery. This ensures that each user has the appropriate access rights and availability based on their role and responsibilities within the organization.

From this screen, you can add new users, create users based on existing profiles, and manage user access to web and mobile applications. It also enables you to define user roles and permissions, assign agencies, configure working schedules, manage days off, and control access to key functional areas such as optimization, missions, depots, tickets, and vehicles.

## Before you begin

* Sign in to **Nomadia Delivery** as an administrator who can create, configure, and maintain user accounts.
* Know which web or mobile access, roles, and permissions each user needs.

## Feature overview

* **Manage User Profile**: Creates multiple profiles with different access rights to simplify user and permission management.
* **Creating a User from an Existing User**: Creates a user based on an existing one.
* **Creating User from a Scratch**: Adds a new user and defines their settings from the beginning.
* **Days off**: Manages the days off of users.
* **Enabling Mobile Access** and **Enabling Web Access**: Control user access to the mobile and web applications.
* **Mobile - Roles and Rights** and **Web - Roles and Rights**: Define user roles and permissions.
* **Auto-Assign Missions to Deliverers**: Automatically assigns missions to the right deliverers and vehicles based on predefined spatial or postal zones.
