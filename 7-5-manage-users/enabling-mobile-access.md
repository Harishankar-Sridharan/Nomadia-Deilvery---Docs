# Enabling Mobile Access

Enable mobile access when you create a user so that the user can work in the mobile application. Mobile users receive their roles and rights from the selected profile and are assigned to an agency.

## Before you begin

* Decide which **Profile Name** applies to the user: **Planner (Standard)**, **Contractor**, or **Subcontractor**.

## Feature overview

* **Planner (Standard)**: Access can be granted to a Transporter.
* **Contractor**: Access can be granted to a Contractor.
* **Subcontractor**: Access can be granted to a Subcontractor.

## Enable mobile access for a user

1. Navigate to **Configuration**.

![](<../.gitbook/assets/image-1 (1).png>)

2. Select **Manage Users** from the list.

![](<../.gitbook/assets/image-2 (1).png>)

3. Click the **Actions** drop-down and choose **Add**.

![](<../.gitbook/assets/image-3 (1).png>)

4. Set **Create from existing user** to **No** to create a new user.
5. Click **OK**. For step-by-step instructions, refer to [Creating a User from an Existing User](creating-a-user-from-an-existing-user.md).

![](<../.gitbook/assets/image-4 (1).png>)

6. Select the appropriate **Profile Name**: **Planner (Standard), Contractor, or Subcontractor.**
7. Enter the **Login ID, First Name**, and **Last Name**.

![](../.gitbook/assets/image-11.png)

8. Set the **User Status** to **Yes** or **No**, as required.
9. Enable **Mobile Access** and enter the **user's Password**. For more information about the password policy, refer to [Password policy for Mobile Access](mobile-roles-and-rights.md#password-policy-for-mobile-access).

![](<../.gitbook/assets/image-6 (1).png>)

10. Open **Roles and Rights** and enable the required permissions.

![](<../.gitbook/assets/image-7 (1).png>)

11. Go to **Agency**, select the available agency, and click the right arrow to assign it to the user.

![](<../.gitbook/assets/image-8 (1).png>)

12. Click **Save** to create the user after completing all required details.

![](<../.gitbook/assets/image-9 (1).png>)

## Tips

{% hint style="info" %}
**Login ID format**: The Login ID is required to be in an email format. For Mobile Users, the login ID is not required to be a valid email address.
{% endhint %}

{% hint style="info" %}
**Inherited roles and rights**: When a profile is selected, all roles and access rights are inherited automatically. Roles and rights cannot be enabled or disabled manually at the user level. To change any roles or access rights, the modifications must be made in the profile configuration.
{% endhint %}
