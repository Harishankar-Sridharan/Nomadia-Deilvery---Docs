# Custom Dashboards

The enhanced dashboard offers advanced features for better data access, visualization, and customization. These improvements enable transporters and subcontractors to manage large datasets more effectively, derive actionable insights, and customize dashboards to meet specific operational requirements.

## Feature overview

* **Pre-defined dashboards**: A set of ready-to-use dashboards that provide actionable insights across different operational areas.
  * **Home Page KPIs**: Enables users to monitor key indicators directly from Nomadia Delivery home page.
  * **Operational Dashboard**: Helps users track delivery performance and identify potential bottlenecks.
  * **Administration Dashboard**: Allows users to review application usage metrics.
  * **Sustainability Dashboard**: Lets users assess carbon footprint and fuel consumption trends.

![](<../.gitbook/assets/image-1 (10).png>)

* **Pre-filters for improved performance**: Users can configure pre-filters, such as Agency, Period, Contractor, and Subcontractor, to define the data shown on the dashboard in advance.
  * By pre-filtering data on the server side, only the necessary information is downloaded, enabling faster chart rendering and smoother performance.
  * This feature is especially useful for users handling large datasets.

![](<../.gitbook/assets/image-2 (10).png>)

## Set up a custom dashboard

Transporters and subcontractors can follow these steps.

1. Open the Nomadia Delivery application and go to the Dashboard tab.
2. Click the ‘+’ button to create a new custom dashboard.
3. Enter a title for the dashboard and click ‘Create’.

![](<../.gitbook/assets/image-3 (10).png>)

4. Optionally, set the dashboard as your home page dashboard by activating the toggle. This can later be accessed via Profile → My Preferences.

5. Click ‘Edit Mode’ to start designing the newly created dashboard, which now appears in the dashboard list.

![](<../.gitbook/assets/image-5 (10).png>)

6. Use the Edit Mode, which provides a drag-and-drop interface for creating personalized dashboards.

![](<../.gitbook/assets/image-7 (10).png>)

7. To add a widget, click ‘Add a widget’. A new widget will appear with a default ‘Counter’ representation.

![](<../.gitbook/assets/image-8 (9).png>)

8. Click the widget to edit its parameters:
   * Select specific KPIs, visual representations (e.g., charts, counters), titles, and icons.
   * Apply advanced aggregation options, such as grouping data by users, agencies, or mission status.
   * Customize dashboards to meet specific roles or operational needs.
9. Choose the desired KPI from the available list (e.g., Missions Delivered). The widget title and icon will automatically update based on the selected KPI.

![](<../.gitbook/assets/image-9 (9).png>)

10. Click ‘Save’. A confirmation notification will appear.

![](<../.gitbook/assets/image-10 (8).png>)

## Edit an existing dashboard

1. Click ‘Edit Mode’ again.

![](<../.gitbook/assets/image-11 (8).png>)

2. Resize widgets by moving the mouse to the bottom corner and dragging them to the desired size.

![](<../.gitbook/assets/image-12 (8).png>)

3. To add more widgets, click ‘Add a widget’. The new widget will occupy available space in the grid.

![](<../.gitbook/assets/image-13 (8).png>)

4. Drag widgets to reposition them as needed.

![](<../.gitbook/assets/image-14 (8).png>)

5. To edit a widget, click it, select the KPI (e.g., Missions Delivered), update the title (e.g., Mission Delivered by Users), and choose the representation (e.g., Horizontal Bar).
6. Set aggregation options (e.g., Aggregated by Users) to display data according to mobile users.
7. Continue adding all required KPIs, applying different representations and aggregations, to complete the dashboard.
8. Once finalized, click ‘Save’ to save all changes.

![](<../.gitbook/assets/image-16 (8).png>)

### Result

The newly created custom dashboard is now ready for regular monitoring by the author.

![](<../.gitbook/assets/image-17 (8).png>)

## Remove a dashboard

1. Click the ‘Edit Mode’ button.
2. Click the ‘Delete’ button to remove the dashboard.

![](<../.gitbook/assets/image-18 (8).png>)

3. In the confirmation popup, click ‘Yes’ to proceed with the deletion.

![](<../.gitbook/assets/image-19 (8).png>)

4. Check the notification that confirms the dashboard has been deleted.

![](<../.gitbook/assets/image-20 (7).png>)

### Result

Deleting dashboards allows transporters to better manage and visualize data, supporting streamlined operations and informed decision-making.
