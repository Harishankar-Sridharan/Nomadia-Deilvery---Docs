## customtemplates

**customtemplates** is a feature in **Nomadia Delivery** to customize customer notification emails. Custom templates provide clear, branded updates directly to your clients. This improves customer communication and streamlines your delivery operations.

#### Getting Started

Prerequisites & System Requirements:

* Active dispatcher or planner account in **Nomadia Delivery**.
* Web browser with an active internet connection.

Initial Setup Steps:

1. Go to **Configuration**.

![Configuration Menu – The screen shows the main platform configuration settings.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_07_to_0_to_21.gif)

2. Scroll down and click **Configure outgoing messages**.

![Configure Outgoing Messages – The screen displays outgoing message settings.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_07_to_0_to_21.gif)

3. Click **Email templates** on the left side of the screen.

![Email Templates – The left-side navigation highlighting email templates is shown.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_21_to_0_to_28.gif)

#### Feature Overview

* **Email templates**: Left-side menu where all your configured templates are listed.

![Email Templates List – The screen displays the email templates work area.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_28.png)

* **Actions**: Dropdown button that opens commands to manage your email templates.

![Actions Menu – The dropdown button with available actions is highlighted.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_28_to_0_to_31.gif)

* **Add**: Menu option to start creating a new email template.

![Add Button – The add option under actions dropdown is highlighted.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_31_to_0_to_36.gif)

* **Customer template**: Selection box used to choose the template type.

![Customer Template – The selection box for setting the template is displayed.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_36_to_0_to_46.gif)

* **Identifier**: Text input field where you define a unique template name.

![Identifier Field – The identifier field with a new value is visible.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_04.png)

* **Email subject**: Text field where you enter the subject line for the email.

![Email Subject Field – The subject text field is populated.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_14.png)

* **Standard mode to advanced**: Switch that toggles the editor interface between standard and advanced editing.

![Mode Switch – The mode switch changing standard to advanced mode is active.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_14_to_1_to_22.gif)

* **Message**: Text editor where you type the email body content.

![Message Editor – The typed message is visible in the text field.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_29.png)

* **Save**: Button at the top right corner that saves your new template.

![Save Button – The save button in the top right corner is clicked.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_29_to_2_to_01.gif)

#### How To: Configure a Custom Customer Email Template

1. Go to **Configuration**.

![Configuration Menu – The screen shows the main platform configuration settings.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_07_to_0_to_21.gif)

2. Scroll down and click **Configure outgoing messages**.

![Configure Outgoing Messages – The screen displays outgoing message settings.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_07_to_0_to_21.gif)

3. Click **Email templates** on the left side of the screen.

![Email Templates – The left-side navigation highlighting email templates is shown.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_21_to_0_to_28.gif)

4. Click **Actions**.

![Actions Menu – The dropdown button with available actions is highlighted.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_28_to_0_to_31.gif)

5. Click **Add**.

![Add Button – The add option under actions dropdown is highlighted.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_31_to_0_to_36.gif)

6. Click **Customer template** to select your custom template.

![Customer Template – The selection box for setting the template is displayed.](../.gitbook/assets/customtemplates-customtemplates_timestamp_0_to_36_to_0_to_46.gif)

7. Enter a unique template name in the **Identifier** field.

![Identifier Field – The identifier field with a new value is visible.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_04.png)

8. Enter your subject line in the **Email subject** field.

![Email Subject Field – The subject text field is populated.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_14.png)

9. Toggle the mode switch from **Standard mode** to **Advanced mode** if desired.

![Mode Switch – The mode switch changing standard to advanced mode is active.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_14_to_1_to_22.gif)

10. Type your template text in the **Message** field.

![Message Editor – The typed message is visible in the text field.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_29.png)

11. Click **Save** in the top right corner to save your changes.

![Save Button – The save button in the top right corner is clicked.](../.gitbook/assets/customtemplates-customtemplates_timestamp_1_to_29_to_2_to_01.gif)

#### Productivity Tips

* 💡 **Mode Toggle**: Toggle **Standard mode** to **Advanced mode** if you want to use advanced editing options.
