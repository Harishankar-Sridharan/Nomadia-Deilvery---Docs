# Manage Studies & Zones:

Use Manage Studies & Zones to work with postal zones and sectorization.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Configuration** tab.
* Open the **Configuration** tab and click **Manage studies and zones** to see the available missions and studies.

## Feature overview

* **Manage Postal Zones**: Lets administrators and logistics managers define and manage geographical delivery zones based on postal codes.
* **Create Postal Zones by Territory Management (Sectorization)**: Generates sectors automatically, balancing territories according to rules you set and aligning them to postal code boundaries.
* **Customize Zones Table**: Lets you choose which fields are displayed for a mission's zones.

## Tips

{% hint style="info" %}
**Postal code prefix**: The Prefix standardizes postal codes to a fixed length of 6 digits, so define it when you add a postal zone.
{% endhint %}

{% hint style="warning" %}
**Postal code data**: Postal code boundary data is unavailable for certain countries, which affects sectorization that aligns to postal code boundaries.
{% endhint %}
