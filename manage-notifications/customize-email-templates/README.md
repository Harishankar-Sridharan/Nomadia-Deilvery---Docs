# Customize Email Templates

In Nomadia Delivery, custom email templates enable planners to personalize communication with end customers according to mission parameters such as customer type or package value. This capability improves operational transparency and boosts customer satisfaction by ensuring timely and relevant messages are delivered.

## Before you begin

To streamline onboarding, Nomadia Delivery offers a collection of pre-configured default templates for both email and SMS:

* These templates are activated by default.
* They act as a fallback when no custom configuration is in place.
* While they cannot be deleted, they can be disabled if required.

![](<../../.gitbook/assets/image-33 (4).png>)

## Feature overview

* **Default templates**: Pre-configured email and SMS templates that are activated by default and act as a fallback when no custom configuration is in place.
* **Configure outgoing messages**: The **Configuration** menu entry where you manage message templates.
* **Email templates** tab: The tab where you add and manage email notification templates.
* **Actions** > **Add**: Lets you choose one of the available templates to customize, for example **Time window to communicate**.
* **Configuration type**: Links a template with the mission.

## Create a custom email notification template

1. Open the Nomadia Delivery application and go to the **Configuration** tab.
2. From the drop-down menu, select **Configure outgoing messages**.
3. Click the **Email templates** tab.

![](<../../.gitbook/assets/image-34 (4).png>)

4. In the table, click the **Actions** button and select **Add**.

![](<../../.gitbook/assets/image-35 (4).png>)

5. Choose one of the available templates to customize (for example, **Time window to communicate**).

![](<../../.gitbook/assets/image-36 (4).png>)

6. In the pop-up window, personalize and configure the message as needed.
7. Select a configuration type to link the template with the mission.
8. Enable the template and save your changes.

![](<../../.gitbook/assets/image-37 (4).png>)

Repeat the process to configure other notifications and associate them with the appropriate configuration types.
