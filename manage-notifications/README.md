# Manage Notifications

The Manage Mission's Notifications enable administrators and dispatchers to configure and automate notifications related to delivery missions. These notifications ensure real-time communication with customers, field agents, and internal stakeholders, improving operational visibility and customer satisfaction.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Configuration** page.
* Open **Configuration**, click **Configuration Menu**, and under **Fulfillment and Client Experience**, click **Configure Outgoing Messages** to reach the notification settings.

## Feature overview

* **Email**: Enables the outgoing email service so that **Nomadia Delivery** can send email notifications to customers.
* **Customize Email Templates**: Lets planners personalize communication with end customers according to mission parameters such as customer type or package value.
* **SMS**: Enables the outgoing SMS service so that **Nomadia Delivery** can send SMS notifications to customers.

## Tips

{% hint style="info" %}
**Default templates**: Pre-configured default email and SMS templates are activated by default and act as a fallback when no custom configuration is in place.
{% endhint %}

{% hint style="warning" %}
**SMS is an additional service**: SMS notifications are provided as an additional service.
{% endhint %}
