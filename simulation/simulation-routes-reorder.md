# Reorder routes

This page explains how to change the order of the stops on the selected routes.

## Before you begin

* Open a simulation. See [Simulation](simulation.md).

## Steps

1. Go to **Simulation** > **Routes**.
2. Select the check boxes of the routes you want to reorder.
3. Click the **Routes** drop-down arrow, and then click **Reorder**.

## Result

You can check the new order in the route view. See [View a route](simulation-routes-view-route.md).

## Tips

{% hint style="warning" %}
**Dynamic pickup & delivery locations**: The **Reorder** option is deactivated for routes that contain dynamic pickup & delivery locations, because this feature is not compatible with this mode. See [Assign pickup and delivery missions](../assignpickupanddelivery.md).
{% endhint %}
