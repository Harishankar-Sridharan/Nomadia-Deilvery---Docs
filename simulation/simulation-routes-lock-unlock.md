# Lock and unlock routes

This page explains how to lock routes to keep them as they are, and how to unlock them again.

## Before you begin

* Open a simulation. See [Simulation](simulation.md).

## Steps

1. Go to **Simulation** > **Routes**.
2. Select the check boxes of the routes you want to lock or unlock.
3. Click the **Routes** drop-down arrow.
4. Click **Lock** to lock the routes, or **Unlock** to unlock them.

## Result

Some actions have no effect on locked routes. For example, **Single route ordering** shows the message **The action had no effect as it concerns only locked routes.** when it only concerns locked routes. See [Order a single route](simulation-deliveries-single-route-ordering.md).
