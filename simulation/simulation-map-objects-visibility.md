# Choose what the map shows

This page explains how to use **Objects visibility** to choose the objects, the map style and the overlays of the **Map** panel.

## Before you begin

* Open a simulation. See [Simulation](simulation.md).

## Steps

1. Go to **Simulation** > **Map**.
2. Click **Objects visibility**.
3. In the table on the left, use the **See** column to show or hide an object type, and the **Selection** column to choose what you can select with the **Selection** tool. The types are **All**, **Routes**, **Planned deliveries**, **Not assigned**, **Departures and arrivals** and **Vehicles**.
4. On the right, select a map style: **Map**, **Black & White**, **Satellite**, **Terrain** or **Public transport**.
5. Use the switches to turn an overlay on or off: **ADMINISTRATIVE MAP**, **ZFE_ZTL**, **COMPLETE**, **Traffic**, **Trucks** or **Delivery clusters**.

![The Objects visibility menu with the object types, the map styles and the overlays](../.gitbook/assets/Simulation_MapObjectsVisibility_001.jpg)

## Result

The map shows the objects, the style and the overlays you chose.
