# Add a break

This page explains how to add a break to a route.

## Before you begin

* Open a simulation. See [Simulation](simulation.md).

## Steps

1. Go to **Simulation** > **Deliveries**.
2. Click the **Deliveries** drop-down arrow, and then click **Add a break**.
3. In the **Add a break** window, enter a **Name** for the break.
4. Enter the **Address**, **Postal code**, **City** and **Country** of the break, and then click **Geolocate**.
5. Enter the **Visit duration**. The default value is **01:00**.
6. Select the **Start time**.
7. Select the **Route** that gets the break.
8. Click **Add**.

Click **Cancel** to close the window without adding a break.

![The Add a break window](../.gitbook/assets/Simulation_DeliveriesAddBreak_001.jpg)

## Result

The break is added to the route you selected, with the name, location, duration and start time you entered.
