# Analyze the results

This page explains how to use the **Analysis** panel to access analysis charts and better understand the results.

## Before you begin

* Open a simulation. See [Simulation](simulation.md).

## Steps

1. Go to **Simulation**.
2. Click **Modify the display of panels**.
3. Drag **Analysis** onto the page.
4. Click the **Analysis** drop-down arrow.
5. Click a chart. The charts are described in [Analysis charts](simulation-analysis-charts.md).

![The Analysis menu open with the list of available charts](../.gitbook/assets/Simulation_Analysis_001.png)

## Features

* [Analysis charts](simulation-analysis-charts.md): Learn what each chart shows.

## Result

The panel shows the chart you selected. Charts show **Planned deliveries** and **Unplanned deliveries** in different colors.

![The Number of deliveries by duration chart in the Analysis panel](../.gitbook/assets/Simulation_Analysis_002.png)

## Tips

{% hint style="info" %}
**Go back to your layout**: Click **Undo layout changes** or **Reset layout** to remove the panel.
{% endhint %}
