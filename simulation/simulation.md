# Simulation

The **Simulation** module shows the result of a route optimization so that you can review, adjust and validate the routes before your deliverers use them.

{% hint style="info" %}
**Panels**: The Simulation page shows panels, not tabs, and each panel has its own topic in this guide. Click **Modify the display of panels** to choose which panels you see.
{% endhint %}

## Before you begin

* Make sure your user profile has the rights needed for simulations. For example, **Optimization** gives access to the optimization features, **Schedule** lets you create and manage optimized schedules, and **See other people's simulations** and **Edit other people's simulations** let you work with simulations created by other users. See [Web - Roles and Rights](../7-5-manage-users/web-roles-and-rights.md).
* Run an optimization from the **Missions** tab. A simulation shows the result of that optimization.

## Features

* [Manage deliveries](simulation-deliveries.md): Find the deliveries in the simulation and optimize, assign, unassign, lock or delete them.
* [View the map](simulation-map.md): See the deliveries and routes on a map and choose what the map shows.
* [Manage routes](simulation-routes.md): Review, validate, reorder, reverse, assign and lock routes.
* [View route details](simulation-details.md): See the totals for distance, deliveries and durations, and the agendas of your resources.
* [Analyze the results](simulation-analysis.md): Access analysis charts to better understand the results.
* [View validated routes](simulation-validated-routes.md): See the routes you validated by route, date and deliverer.

## Result

When the optimization finishes, the **Optimization results** window opens. It shows **Used vehicles**, **Deliveries**, **Total duration**, **Total distance**, **Planned routes**, **Total work duration**, **Drive duration**, **Wait duration**, **Rest duration**, **Average filling rate** and **Optimization duration**. From this window you can click **More results**, **Display the simulation** or **Validate routes**.

![The Optimization results window with charts, totals and the Display the simulation button](../.gitbook/assets/Simulation_Overview_002.png)

## Tips

{% hint style="info" %}
**Open the results again**: Click **Optimization results** in the toolbar to open the **Optimization results** window.
{% endhint %}

{% hint style="info" %}
**Change the panel layout**: Click **Modify the display of panels**, then drag a panel name, for example **Analysis**, onto the page to add it. Click **Undo layout changes** or **Reset layout** to go back.
{% endhint %}

{% hint style="info" %}
**Toolbar buttons**: Use **Optimize**, **See and modify the settings**, **Save changes**, **Export**, **Edit**, **See the list of simulations**, **Optimization results** and **View used and unused vehicles in the optimisation** from the toolbar at the top of the page.
{% endhint %}

{% hint style="warning" %}
**Out-of-date simulation**: A warning icon shows when your configuration, optimization parameters or fleet changed after you created the simulation. To use the new settings, go to the **Missions** tab and start a new optimization.
{% endhint %}
