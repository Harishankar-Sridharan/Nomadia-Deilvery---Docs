# Create a Subcontractor User

Transporters can assign users within each subcontractor to manage planning and execution tasks more effectively. This capability enables the creation of dedicated planners and drivers for every subcontractor, ensuring smooth and efficient management of logistics operations.

## Create a subcontractor user

1. Open the Nomadia Delivery application and go to **Configuration** > **Manage users**.

![](<../.gitbook/assets/image-6 (6).png>)

2. Click the **Action** button and select **Add**.

![](<../.gitbook/assets/image-7 (6).png>)

3. Click **OK** to create a new user. Alternatively, you can create a user from an existing one. This speeds up the process by copying all settings from the existing user to the new one.

![](<../.gitbook/assets/image-8 (5).png>)

4. In the **Generalities** tab, enter the profile, login, and last name of the user, and enable the user status.
5. Go to the **Access** tab.

![](<../.gitbook/assets/image-9 (5).png>)

6. Enable web access for the user and select the subcontractor's website from the drop-down list.

![](<../.gitbook/assets/image-10 (4).png>)

7. Select the correct subcontractor (created in the Subcontractors module) to link with this user.
8. Go to the **Roles & rights** tab. The system automatically assigns rights based on the user.

![](<../.gitbook/assets/image-11 (4).png>)

9. Save the new user. The subcontractor receives an email notification with instructions to create a password and activate the account.

![](<../.gitbook/assets/image-12 (4).png>)

## Activate the subcontractor account

The subcontractor must complete these steps:

1. Click the verification link in the email.
2. Enter the verification code received by email and click **Verify code**.
3. Click **Continue**.
4. Enter and confirm a new password, then click **Continue**.
5. Accept the end-user license agreement, then click **Continue**.

## Tips

{% hint style="info" %}
**Missing subcontractor**: If no subcontractor appears in the list, ensure one has been created in the Subcontractors module.
{% endhint %}
