# adhocaddresscreation

Create and save a new address on the fly while adding a machine in Nomadia Delivery. This eliminates pre-configuring location data beforehand, saving setup time for dispatchers. Assign new addresses directly to specific contracts or store them in the global address list.

### Getting Started

- Access to **Nomadia Delivery** with dispatcher permissions.
- Valid **Machine Type**, **Contract**, and **Agency** details.

1. Navigate to the **Machine** menu in **Nomadia Delivery**.

![Flow 0:13 to 0:21](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_13_to_0_to_21.gif "Machine Menu – Navigating to the Machine menu and selecting Add from Actions.")

2. Click **Actions** and select **Add**.

![Frame at 0:21](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_21.png "Actions Menu – Displaying the Add option under Actions.")

### Feature Overview

- **Contract Field**: Selects the associated contract test for the address. If left blank, the address saves to the global address list.

![Frame at 0:30](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_30.png "Contract Field – Selecting a contract test to attach the address.")

- **Machine Type Field**: Specifies the machine category during setup. Ensures correct asset classification.

![Frame at 0:36](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_36.png "Machine Type Field – Selecting the machine type for configuration.")

- **Agency Field**: Defines the assigned agency for the machine and address record. Ensures proper organizational routing.

![Frame at 0:44](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_44.png "Agency Field – Selecting the agency for organizational setup.")

- **Next Button**: Advances from initial details to the address configuration form. Moves the workflow forward.

![Frame at 0:48](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_48.png "Next Button – Clicking Next to open the address input step.")

- **Create Button**: Confirms initial address entry and opens detailed field mapping. Generates the location record.

![Frame at 1:06](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_06.png "Create Button – Saving initial address data to proceed.")

- **Binded Fields Dropdown**: Maps required location properties and fields to the address record. Ensures data completeness.

![Frame at 1:24](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_24.png "Binded Fields Dropdown – Mapping location properties to the address.")

- **Add Button**: Finalizes and saves the on-the-fly address to the system. Completes address creation.

![Frame at 1:29](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_29.png "Add Button – Saving the address permanently.")

- **Contractors Menu**: Accesses contractor profiles and associated address records. Allows verification of saved addresses.

![Frame at 1:42](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_42.png "Contractors Menu – Accessing saved contractor records.")

- **Address List Tab**: Displays all saved location addresses for a selected contractor. Provides confirmation of created locations.

![Frame at 2:03](adhocaddresscreation-adhocaddresscreation_timestamp_2_to_03.png "Address List Tab – Viewing the list of saved addresses.")

### How To: Create an Ad-Hoc Address

1. Navigate to the **Machine** screen and click **Actions**.

![Flow 0:13 to 0:21](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_13_to_0_to_21.gif "Machine Screen – Opening Actions and clicking Add.")

2. Select **Add** from the drop-down menu.

![Frame at 0:21](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_21.png "Add Option – Clicking Add to initiate setup.")

3. Select the **Contract** test, **Machine Type**, and **Agency**.

![Flow 0:21 to 0:44](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_21_to_0_to_44.gif "Form Selection – Selecting contract test, machine type, and agency values.")

4. Click **Next**.

![Frame at 0:48](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_48.png "Next Button – Moving to the address details entry step.")

5. Enter the address information that needs to be saved.

![Flow 0:48 to 1:00](adhocaddresscreation-adhocaddresscreation_timestamp_0_to_48_to_1_to_00.gif "Address Input – Entering location details into the address field.")

6. Click **Create**.

![Frame at 1:06](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_06.png "Create Button – Proceeding to field mapping.")

7. Enter the additional address details.

![Flow 1:06 to 1:16](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_06_to_1_to_16.gif "Address Entry – Entering specific location data.")

8. Select the **Binded Fields** options.

![Frame at 1:24](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_24.png "Binded Fields – Mapping required data fields.")

9. Click **Add** to complete saving the address.

![Frame at 1:29](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_29.png "Add Button – Finalizing creation of the new address.")

### How To: Review a Saved Address

1. Click **Contractors** in the main menu.

![Frame at 1:42](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_42.png "Contractors Menu – Opening contractor records.")

2. Select the specific contractor from the list.

![Frame at 1:48](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_48.png "Contractor Selection – Choosing the target contractor profile.")

3. Select the appropriate **Binded Fields**.

![Frame at 1:52](adhocaddresscreation-adhocaddresscreation_timestamp_1_to_52.png "Binded Fields Selection – Setting filter parameters.")

4. Click **Address List**.

![Frame at 2:03](adhocaddresscreation-adhocaddresscreation_timestamp_2_to_03.png "Address List – Opening the saved addresses tab.")

5. Review the saved address entries.

![Frame at 2:09](adhocaddresscreation-adhocaddresscreation_timestamp_2_to_09.png "Saved Address Display – Confirming saved location details.")

### Productivity Tips

- 💡 **Global Address Assignment**: Leave the **Contract** selection unselected to automatically save the address to the global address list for company-wide use.
- ⚠️ **Contract Assignment Omission**: Avoid leaving the **Contract** field blank if the address must be restricted to a specific contract.
- 💡 **Saved Address Review**: Navigate through **Contractors** to **Address List** to quickly verify newly created addresses.
