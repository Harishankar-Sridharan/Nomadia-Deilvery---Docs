# alertmanagement

Alert Threshold Management in **Nomadia Delivery** allows dispatchers to set operational trigger limits. This feature helps planners monitor disruptions like late departures, route delays, and overtime in real time. Configure alert rules to maintain full operational oversight and improve delivery reliability.

### Getting Started

Prerequisites:
- Active dispatcher account for **Nomadia Delivery**.
- Permissions to access the **Configuration** menu.

Setup Steps:
1. Select **Configuration** in the main navigation menu.

![Flow 0:05 to 0:09](alertmanagement-alertmanagement_timestamp_0_to_05_to_0_to_09.gif "Configuration Menu – Opening the main configuration settings menu.")

2. Click **Alert Threshold Management** under the root options.

![Frame at 0:22](alertmanagement-alertmanagement_timestamp_0_to_22.png "Alert Threshold Management Page – Opening the threshold configuration page.")

### Feature Overview

- **Red Icon**: Icon located in the top right corner to access the pre-filter modal.

![Frame at 0:28](alertmanagement-alertmanagement_timestamp_0_to_28.png "Red Icon – Location of the pre-filter action icon.")

- **Pre-filter**: Modal menu to select previous search criteria and agency filters.

- **Quantitative Alert**: View that lists active numerical alert thresholds and live alerts.

- **Finished Alert**: View that archives completed and resolved alerts for historical tracking.

![Frame at 1:23](alertmanagement-alertmanagement_timestamp_1_to_23.png "Finished Alert View – Displaying resolved and completed alerts.")

- **Add Alert**: Action button that opens the menu to create new alert rules.

![Frame at 1:29](alertmanagement-alertmanagement_timestamp_1_to_29.png "Add Alert Button – Opening the menu to add new operational alerts.")

- **Time Threshold**: Input box to specify duration limits for triggering alerts.

![Frame at 1:51](alertmanagement-alertmanagement_timestamp_1_to_51.png "Time Threshold Field – Configuring time duration trigger limits.")

- **Late Departure**: Alert triggered when vehicle departure is delayed beyond scheduled time.

![Frame at 2:08](alertmanagement-alertmanagement_timestamp_2_to_08.png "Late Departure Alert – Threshold trigger for delayed vehicle departures.")

- **ETA Delay**: Alert triggered when ETA (estimated time of arrival) is delayed.

![Frame at 2:19](alertmanagement-alertmanagement_timestamp_2_to_19.png "ETA Delay Alert – Threshold trigger for arrival time delays.")

- **ETA Change**: Alert triggered when the estimated arrival time for an order changes.

![Frame at 2:28](alertmanagement-alertmanagement_timestamp_2_to_28.png "ETA Change Alert – Threshold trigger for order ETA modifications.")

- **Overtime**: Alert triggered when vehicle arrival exceeds set working time limits.

![Frame at 2:37](alertmanagement-alertmanagement_timestamp_2_to_37.png "Overtime Alert – Threshold trigger for exceeding working time limits.")

- **Excessive Idle Time**: Alert triggered when a vehicle remains stationary for too long.

![Frame at 2:45](alertmanagement-alertmanagement_timestamp_2_to_45.png "Excessive Idle Time Alert – Threshold trigger for excessive vehicle idling.")

- **Validation Too Far From Address**: Alert triggered when validation location is too far from actual address.

- **Excessive Scan**: Alert triggered when package scan counts exceed expected limits.

![Frame at 3:02](alertmanagement-alertmanagement_timestamp_3_to_02.png "Excessive Scan Alert – Threshold trigger for unexpected scan counts.")

- **Closing Soon**: Alert triggered when destination location closing time is approaching.

![Frame at 3:09](alertmanagement-alertmanagement_timestamp_3_to_09.png "Closing Soon Alert – Threshold trigger for approaching location closing times.")

- **RZ Machine Response**: Alert triggered when a driver responds to an RZ machine (driver communication terminal) prompt.

### How To: Pre-Filter Alerts

1. Click the **Red Icon** in the top right corner of the **Alert Threshold Management** page.

![Flow 0:28 to 0:32](alertmanagement-alertmanagement_timestamp_0_to_28_to_0_to_32.gif "Red Icon – Clicking the pre-filter icon.")

2. Select the previous search criteria from the **Previous** field.

![Frame at 0:43](alertmanagement-alertmanagement_timestamp_0_to_43.png "Previous Field – Selecting previous filter criteria.")

3. Select the target agency from the **Agency** drop-down menu.

![Frame at 0:50](alertmanagement-alertmanagement_timestamp_0_to_50.png "Agency Drop-down – Selecting the agency filter.")

4. Click **Apply** to run the pre-filter.

![Flow 0:50 to 0:57](alertmanagement-alertmanagement_timestamp_0_to_50_to_0_to_57.gif "Apply Button – Applying the selected filters.")

### How To: View Active and Finished Alerts

1. Review filtered alert details on the **Alert Threshold Management** page.

![Frame at 1:05](alertmanagement-alertmanagement_timestamp_1_to_05.png "Alert Details Page – Viewing pre-filtered alert records.")

2. Select **Quantitative Alert** to inspect active quantitative thresholds.

![Frame at 1:10](alertmanagement-alertmanagement_timestamp_1_to_10.png "Quantitative Alert Tab – Displaying live quantitative alerts.")

3. Select **Finished Alert** to inspect completed operational alerts.

![Frame at 1:23](alertmanagement-alertmanagement_timestamp_1_to_23.png "Finished Alert Tab – Displaying historical completed alerts.")

### How To: Configure a New Alert Threshold

1. Click **Add Alert** on the **Alert Threshold Management** page.

![Flow 1:23 to 1:29](alertmanagement-alertmanagement_timestamp_1_to_23_to_1_to_29.gif "Add Alert Button – Opening the alert configuration modal.")

2. Select the desired alert type from the **Multiple Alerts** list.

![Frame at 1:34](alertmanagement-alertmanagement_timestamp_1_to_34.png "Multiple Alerts List – Selecting an alert type.")

3. Enter the threshold value in the **Time Threshold** input field.

![Flow 1:43 to 1:56](alertmanagement-alertmanagement_timestamp_1_to_43_to_1_to_56.gif "Time Threshold Field – Setting the duration threshold value.")

4. Click **Save** to confirm and activate the new alert threshold.

![Flow 1:34 to 1:43](alertmanagement-alertmanagement_timestamp_1_to_34_to_1_to_43.gif "Save Button – Saving the configured alert.")

5. Click **Cancel** to discard changes and close the setup window.

![Flow 3:20 to 3:29](alertmanagement-alertmanagement_timestamp_3_to_20_to_3_to_29.gif "Cancel Button – Discarding changes and exiting.")

### Productivity Tips

- 💡 **Agency Pre-Filtering**: Select agency pre-filters to isolate specific operational units and speed up alert searches.
- 💡 **Historical Alert Auditing**: Check the finished alert tab to review historical alert resolutions and evaluate driver performance.
- ⚠️ **Unsaved Configurations**: Avoid navigating away without clicking save when configuring thresholds or changes will be lost.
