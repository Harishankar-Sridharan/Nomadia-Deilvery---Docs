# Manage Container Types

The Manage Container Types feature enables logistics managers and dispatchers to define, configure, and manage the various types of containers or packaging units used in delivery operations. This helps optimize space planning, improve tracking, and ensure accurate handling of goods during transport.

## Feature overview

* **Default container types**: The system supports three default container types: Cardboard, Pallet, and Parcel.
* **Grouping and quantities**: You can group multiple containers together and track the quantity of each container type at client locations for better inventory and logistics management.

6. Enter the **Code** and **Translation**.

## Edit a container type

1. Go to **Configuration**.
2. Click the **Configuration** menu.
3. Under Customization, click **Container Types**.
4. Click the **Pencil** icon of the chosen container type.
5. Edit the information as needed.

<figure><img src="../.gitbook/assets/image (102) (1).png" alt=""><figcaption></figcaption></figure>

6. Click **Save**.

<figure><img src="../.gitbook/assets/image (103) (1).png" alt=""><figcaption></figcaption></figure>

## Delete a container type

1. Go to **Configuration**.
2. Click the **Configuration** menu.
3. Under Customization, click **Container Types**.
4. Select the container types.
5. Click **Actions**.
6. Click **Delete**.

<figure><img src="../.gitbook/assets/image (104) (1).png" alt=""><figcaption></figcaption></figure>

### Result

The container type is deleted successfully.
