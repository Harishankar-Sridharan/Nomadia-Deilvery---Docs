# Edit a Container Type

Use this procedure to change the settings of an existing container type, such as the options that control how status, attributes and documents are inherited between parent and child missions.

## Before you begin

* Access to the **Configuration** menu in **Nomadia Delivery**.

## Steps

1. Go to **Configuration**. 2. Click on **Configuration Menu** 3. Under Delivery Section, click on **Container Types** 4. Click the Pencil icon of the chosen container type 5. Edit the information as needed 6. Click on **Save**  <figure><img src="../.gitbook/assets/EditContainerType_Steps_001.png" alt="Click on Save"><figcaption></figcaption></figure>

### Result

The container type is updated with your changes.
