# auditlogs

The **auditlogs** feature in Nomadia Delivery tracks and records system activity and recent changes made across the platform. Dispatchers and planners need it to maintain operational oversight, verify modifications, and audit configuration actions. Using this tool, you can review change history, filter logs by agent or timeframe, and export records to Excel.

### Getting Started

Prerequisites and system requirements:
- Active access to a **Nomadia Delivery** dispatcher or planner account.
- Permissions to view system **Configuration** and **History of Changes**.

Initial setup steps:
1. Navigate to **Configuration** in the main navigation menu.

   ![Flow 0:05 to 0:12](auditlogs-auditlogs_timestamp_0_to_05_to_0_to_12.gif "Configuration – Navigating to the Configuration menu section.")

2. Scroll down and click **History of Changes**.

   ![Frame at 0:12](auditlogs-auditlogs_timestamp_0_to_12.png "History of Changes – Accessing the audit logs interface.")

### Feature Overview

- **Date and Time**: Displays the exact timestamp when a change occurred.

  ![Frame at 0:17](auditlogs-auditlogs_timestamp_0_to_17.png "Date and Time – Viewing the timestamp of recent system changes.")

- **Login Details**: Shows the user account responsible for the modification.

  ![Frame at 0:23](auditlogs-auditlogs_timestamp_0_to_23.png "Login Details – Displaying the user account responsible for changes.")

- **Object Name**: Identifies the specific item or record changed.

  ![Frame at 0:26](auditlogs-auditlogs_timestamp_0_to_26.png "Object Name – Showing the specific item affected by the change.")

- **Type**: Indicates the category of the recorded change.

  ![Frame at 0:28](auditlogs-auditlogs_timestamp_0_to_28.png "Type – Displaying the change category.")

- **Report**: Reflects user-defined reports created or modified in the platform.

  ![Frame at 0:29](auditlogs-auditlogs_timestamp_0_to_29.png "Report – Displaying user-defined report entries.")

- **Profile**: Displays the user profile associated with the activity.

  ![Frame at 0:36](auditlogs-auditlogs_timestamp_0_to_36.png "Profile – Showing the user profile linked to the activity.")

- **Object ID**: Shows the unique system identifier for the modified item.

  ![Frame at 0:40](auditlogs-auditlogs_timestamp_0_to_40.png "Object ID – Displaying the unique database identifier.")

- **Action**: Allows exporting displayed change records to an Excel file.

  ![Frame at 0:44](auditlogs-auditlogs_timestamp_0_to_44.png "Action – Exporting audit log records to an Excel file.")

- **Reload**: Refreshes the log table to display recent changes if loading fails.

  ![Frame at 0:53](auditlogs-auditlogs_timestamp_0_to_53.png "Reload – Refreshing the audit log table to load recent changes.")

- **Refilter**: Opens options to filter log entries by agent or time period.

  ![Frame at 1:08](auditlogs-auditlogs_timestamp_1_to_08.png "Refilter – Opening filter controls to refine audit log results.")

### How To: View and Export Audit Logs

1. Navigate to **Configuration** and scroll down to click **History of Changes**.

   ![Flow 0:05 to 0:12](auditlogs-auditlogs_timestamp_0_to_05_to_0_to_12.gif "History of Changes – Opening the audit logs screen.")

2. Review the table showing **Date and Time**, **Login Details**, **Object Name**, **Type**, **Report**, **Profile**, and **Object ID**.

   ![Frame at 0:17](auditlogs-auditlogs_timestamp_0_to_17.png "Audit Log Table – Displaying recent system modifications.")

3. Click **Action** above the recent changes table.

   ![Frame at 0:44](auditlogs-auditlogs_timestamp_0_to_44.png "Action Button – Selecting the action button to access export options.")

4. Select export to download the log data into an Excel spreadsheet.

   ![Frame at 0:48](auditlogs-auditlogs_timestamp_0_to_48.png "Excel Export – Downloading audit records to an Excel file.")

#### Troubleshooting

- **Logs or file fail to load**: Click **Reload** to fetch the most recent system changes.

  ![Frame at 0:53](auditlogs-auditlogs_timestamp_0_to_53.png "Reload Button – Refreshing the page when logs fail to load.")

### How To: Filter Audit Logs by Agent and Time Period

1. Click **Refilter** on the **History of Changes** screen.

   ![Frame at 1:08](auditlogs-auditlogs_timestamp_1_to_08.png "Refilter Button – Accessing log filtering controls.")

2. Select the target agent or agency from the **Agent** dropdown menu.

   ![Frame at 1:13](auditlogs-auditlogs_timestamp_1_to_13.png "Agent Filter – Selecting an agent to filter log entries.")

3. Choose a time range under **Period**, such as last hours, twenty-four hours, seven days, or twenty-four days.

   ![Frame at 1:29](auditlogs-auditlogs_timestamp_1_to_29.png "Period Selection – Choosing a predefined time window for audit logs.")

4. Select **Custom** to set a specific custom date range.

   ![Frame at 1:35](auditlogs-auditlogs_timestamp_1_to_35.png "Custom Period – Defining a custom date filter range.")

### Productivity Tips

- 💡 **Reload Failed Logs**: Click reload whenever log entries fail to load to display recent system changes immediately.
- 💡 **Custom Date Search**: Select the custom period option to isolate specific timeframe windows during audits.
- ⚠️ **Unloaded Data Assumption**: Avoid assuming no changes occurred if the list is blank; click reload to fetch missing logs.
