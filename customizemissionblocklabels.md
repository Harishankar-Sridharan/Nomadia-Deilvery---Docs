# customizemissionblocklabels

**Customized Machine Block Labels** allow dispatchers to modify default field labels within Nomadia Delivery. Customize predefined field names to align with your fleet operations and terminology. Achieve consistent label formatting across machine creation and editing interfaces.

### Getting Started

#### Prerequisites
- Access to **Nomadia Delivery** with administrative configuration privileges.
- Active connection to the **Configuration** module.

#### Initial Setup Steps
1. Navigate to **Configuration** in the main menu.

![Flow 0:05 to 0:08](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_05_to_0_to_08.gif "Configuration – Open system settings to access customization options.")

2. Select **Customization** from the options menu.

![Flow 0:08 to 0:14](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_08_to_0_to_14.gif "Customization – Expand customization settings under configuration.")

3. Click **Customized Machine Block Labels** to open label settings.

![Flow 0:14 to 0:17](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_14_to_0_to_17.gif "Customized Machine Block Labels – Open predefined label settings.")

### Feature Overview

- **Predefined Information**: Displays default label fields available when creating or editing a machine.

![Frame at 0:32](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_32.png "Predefined Information – Shows default labels for machine creator and editor.")

- **General Information**: Allows users to enter custom label names for machine block fields.

![Frame at 0:57](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_57.png "General Information – Select field category to edit label names.")

- **Save**: Applies custom label changes to the machine creator and editor.

![Frame at 1:15](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_15.png "Save – Store modified block label configurations.")

- **Machine Creator**: Displays customized labels when adding new machines.

![Frame at 1:44](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_44.png "Machine Creator – Form displaying updated custom labels during creation.")

- **Machine Editor**: Displays customized labels when editing existing machine entries.

![Frame at 2:01](customizemissionblocklabels-customizemissionblocklabels_timestamp_2_to_01.png "Machine Editor – Form displaying updated custom labels during editing.")

### How To: Customize and Verify Block Labels

#### Task 1: Customizing Machine Block Labels
1. Click **General Information** in the customized block labels menu.

![Flow 0:52 to 0:57](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_52_to_0_to_57.gif "General Information – Click to open editable label fields.")

2. Enter new text in the label fields.

![Flow 0:57 to 1:04](customizemissionblocklabels-customizemissionblocklabels_timestamp_0_to_57_to_1_to_04.gif "Field Editing – Enter new label names in general information fields.")

3. Click **Save** to apply your changes.

![Flow 1:04 to 1:15](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_04_to_1_to_15.gif "Save – Click save button to store updated labels.")

4. Confirm updated names appear in the list.

![Frame at 1:25](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_25.png "Updated Names – Review updated label names in configuration list.")

#### Task 2: Verifying Labels in Machine Creator
1. Click **Machine** in the main menu.

![Flow 1:25 to 1:44](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_25_to_1_to_44.gif "Machine Navigation – Go to machine management screen.")

2. Click **Add** to open the machine creator.

![Flow 1:44 to 1:58](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_44_to_1_to_58.gif "Add Machine – Click add to open machine creator form.")

3. Verify updated labels display in the form.

![Frame at 1:58](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_58.png "Machine Creator Form – Check custom labels on creation form.")

#### Task 3: Verifying Labels in Machine Editor
1. Select a machine and click **Edit**.

![Flow 1:58 to 2:01](customizemissionblocklabels-customizemissionblocklabels_timestamp_1_to_58_to_2_to_01.gif "Edit Machine – Click edit button on selected machine.")

2. Verify updated labels display in the editor form.

![Frame at 2:07](customizemissionblocklabels-customizemissionblocklabels_timestamp_2_to_07.png "Machine Editor Form – Check custom labels on editor form.")

3. Click **Go back** to exit the editor.

![Flow 2:07 to 2:13](customizemissionblocklabels-customizemissionblocklabels_timestamp_2_to_07_to_2_to_13.gif "Go Back – Return to machine list view.")

4. Click **Edit** again to re-verify custom labels.

![Flow 2:13 to 2:19](customizemissionblocklabels-customizemissionblocklabels_timestamp_2_to_13_to_2_to_19.gif "Re-verify Edit – Click edit again to confirm stored label changes.")

### Productivity Tips

- 💡 **Automated Synchronization**: Updating predefined information automatically syncs label changes across both the machine creator and machine editor.
- ⚠️ **Variable Field Scope**: Avoid assuming all label updates appear everywhere, as certain predefined changes apply exclusively to the machine creator.
