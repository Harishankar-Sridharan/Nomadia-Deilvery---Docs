# Prioritizing a mission

Prioritization allows users to set the urgency of a mission to ensure it is handled according to specific timelines or customer commitments. The system supports manual priority assignment, automatic assignment based on dates, and priority recalculation during route optimization.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page.
* Identify the mission or missions to prioritize, because you select them before you use the **Actions** menu.

## Feature overview

* **Prioritize**: The button in the **Actions** menu that sets the priority of the selected missions.
* **Priority level**: The urgency you set for a mission: **Normal**, **High**, or **Highest**.
* **Manual priority assignment**: Lets you set the urgency of a mission yourself.
* **Automatic assignment**: Assigns priority based on dates.
* **Priority recalculation**: Updates priority during route optimization.

## Manual priority assignment

1. Select the **mission(s)** to be prioritized.

## Tips

{% hint style="info" %}
**Select several missions at once**: You can select multiple missions and prioritize them together from the **Actions** menu.
{% endhint %}

{% hint style="info" %}
**Match priority to commitments**: Set the urgency of a mission so it is handled according to specific timelines or customer commitments. Priority can also be assigned automatically based on dates, as described in Automatic Priority via Delivery Dates.
{% endhint %}
