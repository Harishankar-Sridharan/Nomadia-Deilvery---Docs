# Select Missions from the map

Select missions from the Map view to highlight them by region and work with them in the table view.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page.
* Open the **Map view**, where the missions you want to select are displayed.

## Feature overview

* **Map view**: Displays the missions on a map so you can select them by region.
* **Selection button**: Lets you choose the selection method, for example Polygon or Circle.
* **Table view**: Shows the selected missions on the left panel.

## Select missions from the map

1. From the **Map view**, use the **Selection** button to choose the **selection method** (for example, Polygon or Circle).

<figure><img src="../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure>

2. Draw or select the region to highlight missions.

### Result

The selected missions appear in the table view on the left panel.

## Tips

{% hint style="info" %}
**Work by region**: Choose a selection method, such as Polygon or Circle, and draw the region to highlight missions. The selected missions appear in the table view on the left panel.
{% endhint %}
