# Select Missions from the map

Select missions from the Map view to highlight them by region and work with them in the table view.

## Select missions from the map

1. From the **Map view**, use the **Selection** button to choose the **selection method** (for example, Polygon or Circle).

<figure><img src="../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure>

2. Draw or select the region to highlight missions.

<figure><img src="../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure>

### Result

The selected missions appear in the table view on the left panel.

<figure><img src="../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure>
