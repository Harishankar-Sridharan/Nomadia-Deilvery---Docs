# Custom Fields

Use these pages to create, organize, and apply custom fields in Nomadia Delivery.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Configuration** tab.
* Identify the objects you want to link custom fields to, such as missions, contractors, or addresses.

## Feature overview

* **Creating Custom Fields while Importing**: Dynamically adds new fields during the import process, linked to Contractors, Missions, or Addresses.
* **Inherit mission data from contractor & address list**: Automatically initializes custom field data during mission creation, minimizing manual input.
* **Configuring Mission Visibility**: Extends visibility restrictions to include custom field-based rules, in addition to agency-based controls.
* **Grouping Custom Field**: Groups custom fields in the mission creation form using a group name.
* **Color coding the custom fields**: Covered on its own page, linked in the list below.

## Tips

{% hint style="info" %}
**Inheritance priority**: When a custom field is initialized from both the contractor and the address list, the address list value takes priority over the contractor value.
{% endhint %}

{% hint style="warning" %}
**One visibility field**: Mission visibility can be activated for only one custom field at a time, and the toggle is available only for custom fields of the List of Values type.
{% endhint %}
