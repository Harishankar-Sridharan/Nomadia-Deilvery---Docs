# Import Missions

Import missions from an Excel file on the Missions page to create many missions at once.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page.
* Have an Excel file on your local system that contains the missions to import.
* Know whether your sheet provides the address field or the latitude and longitude fields for the mission locations, because you map one of them during the import.

## Feature overview

* **Actions**: Opens the dropdown menu on the Missions page that contains **Import**.
* **Browse (Excel)**: Lets you choose the **Desired Excel file** from your local system.
* **Validate**: Processes the selected Excel sheet and dataset so you can review the preview.
* **Table view and map view**: Show the preview of the data before the import.
* **Location mapping**: Maps either the address field or the latitude and longitude fields for the mission locations.
* **Import**: Creates the missions from the validated data.

## Import missions from an Excel file

1. From the Missions page, click **Actions**.
2. Select **Import** from the dropdown menu.

<figure><img src="../../.gitbook/assets/image (150).png" alt=""><figcaption></figcaption></figure>

3. Click **Browse (Excel)**.

<figure><img src="../../.gitbook/assets/image (151).png" alt=""><figcaption></figcaption></figure>

4. Choose the **Desired Excel file** from your local system to upload and import it.

<figure><img src="../../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

5. Review the preview of the available Excel sheets, select the required dataset, and click **Validate**.

<figure><img src="../../.gitbook/assets/msedge_TfwOe3eGy9.png" alt=""><figcaption></figcaption></figure>

6. Review the preview of the data, which is displayed in both the table view and the map view.

<figure><img src="../../.gitbook/assets/msedge_VJGR6lqjk1.png" alt=""><figcaption></figcaption></figure>

7. Map either the address field or the latitude and longitude fields for the mission locations.

<figure><img src="../../.gitbook/assets/msedge_NAlcYnDFa9.png" alt=""><figcaption></figcaption></figure>

8. Click **Import**.

<figure><img src="../../.gitbook/assets/msedge_rS5AKwA574.png" alt=""><figcaption></figcaption></figure>

### Result

Missions are imported successfully.

## Tips

{% hint style="info" %}
**Preview before importing**: Review the preview of the data in both the table view and the map view before you click **Import**.
{% endhint %}

{% hint style="info" %}
**Choose one location method**: Map either the address field or the latitude and longitude fields for the mission locations. To improve address geocoding, see Improve the Missions addresses geocoding.
{% endhint %}
