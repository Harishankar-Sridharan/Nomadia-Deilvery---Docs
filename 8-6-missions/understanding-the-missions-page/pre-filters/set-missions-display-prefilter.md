# Set missions display (prefilter)

Set the missions display by choosing prefilter options on the Missions page.

## Feature overview

* **Agency**: Select one or more agencies.
* **Reference**: Filter by creation date or modification date.
* **Period**: Choose from options like the last hour, last 24 hours, last 7 days, or set a custom date range.
* **Display Deleted Missions**: Enable this option to include deleted missions.

## Set the missions display

From the Missions page:

1. Click the **Prefiltered On** button at the top left. The display of this section may vary based on screen resolution.
2. Choose your filters.
3. Click **Apply**.

![](<../../../.gitbook/assets/image-2 (3).png>)

### Result

The filtered missions are displayed on your Missions page.
