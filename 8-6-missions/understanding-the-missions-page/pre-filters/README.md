# Pre-filters

The pre-filters on the Missions page are dynamic sections that provide you with detailed and contextual information based on your current selection or interaction. They enhance navigation and productivity by allowing quick access to relevant data without switching screens.

<figure><img src="../../../.gitbook/assets/image (223).png" alt=""><figcaption></figcaption></figure>

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page.

## Feature overview

* **Set missions display (prefilter)**: Lets you choose prefilter options on the Missions page, such as agency, reference, and period, and apply them to set the missions display.
* **Configure Mission Pre-filters**: Creates custom filter rules based on mission status and type, which you can assign to users to control the missions they see.

## Tips

{% hint style="info" %}
**Quick access to data**: Pre-filters give you quick access to relevant data without switching screens, which enhances navigation and productivity.
{% endhint %}

{% hint style="warning" %}
**Assigned pre-filters limit visibility**: Leaving a pre-filter assigned prevents dispatchers from viewing the full fleet until the assignment is removed. See Configure Mission Pre-filters for details.
{% endhint %}
