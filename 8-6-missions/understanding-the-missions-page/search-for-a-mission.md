# Search for a Mission

Search for a mission on the Missions page using one of several fields.

## Feature overview

You can search using any of the following fields:

* **Mission Number**
* **Sender Barcode**
* **Phone Number**
* **Customer Name**
* **Postal Code**
* **City**

## Search for a mission

1. Click the **Search** icon.

2. Enter the **Desired Criterion** in the input field.
