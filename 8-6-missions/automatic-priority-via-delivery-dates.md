# Automatic Priority via Delivery Dates

The system automatically sets the priority of a mission to Highest based on its commitment dates. You can also recalculate priorities when you optimize missions or routes.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to missions.
* Have the commitment dates for the mission ready, for example the **Delivery Asked Date** and **Delivery Asked End Date**.
* To recalculate priorities, select the missions or the parent route you want to optimize.

## Feature overview

* **Delivery Information**: The section of the mission creation or edit screen that holds the commitment dates.
* **Delivery Asked Date** and **Delivery Asked End Date**: The commitment dates that the system uses to set the priority to Highest.
* **Optimize**: The action in the Actions menu that starts an optimization of the selected missions or parent route.
* **Recalculate Priorities toggle**: When switched to ON, recalculates priorities during the optimization.

## Set priority automatically from delivery dates

1. Open the **mission creation** or **edit** screen.
2. Navigate to **Delivery Information**.
3. Populate the **Delivery Asked Date** and **Delivery Asked End Date.**

<figure><img src="../.gitbook/assets/image (3) (1) (1).png" alt=""><figcaption></figcaption></figure>

4. Save the mission.

<figure><img src="../.gitbook/assets/image (3) (1) (1).png" alt=""><figcaption></figcaption></figure>

### Result

The system automatically sets the priority to Highest based on these commitment dates.

## Recalculate priorities during optimization

1. Select the **missions** or **parent route** for optimization.

<figure><img src="../.gitbook/assets/image (5) (1).png" alt=""><figcaption></figcaption></figure>

2. Click **Optimize** from the Actions menu.

<figure><img src="../.gitbook/assets/image (6) (1).png" alt=""><figcaption></figcaption></figure>

3. Switch the **Recalculate Priorities toggle** to ON.

<figure><img src="../.gitbook/assets/image (7) (1).png" alt=""><figcaption></figcaption></figure>

4. Run the **optimization**.

<figure><img src="../.gitbook/assets/image (8) (1).png" alt=""><figcaption></figcaption></figure>

## Tips

{% hint style="info" %}
**Populate both dates**: Fill in the **Delivery Asked Date** and **Delivery Asked End Date** and save the mission so the system can set the priority to Highest from the commitment dates.
{% endhint %}

{% hint style="info" %}
**Recalculate when optimizing**: Switch the **Recalculate Priorities toggle** to ON before you run the optimization to recalculate priorities for the selected missions or parent route.
{% endhint %}
