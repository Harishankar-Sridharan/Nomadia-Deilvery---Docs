# Bulk Edit Mission Data

Bulk editing mission data enables large-scale updates to mission information, reducing manual effort and saving time by avoiding repetitive tasks. This feature improves efficiency while maintaining control and data integrity across teams.

## Create bulk edit configuration

1. From the main header, click the **Missions** page.

<figure><img src="../.gitbook/assets/image (192).png" alt=""><figcaption></figcaption></figure>

2. Choose the missions you’re interested in from the mission table.

<figure><img src="../.gitbook/assets/image (193).png" alt=""><figcaption></figcaption></figure>

3. Enter a **Name** for the bulk edit configuration in the Bulk Edit pop-up.

<figure><img src="../.gitbook/assets/image (194).png" alt=""><figcaption></figcaption></figure>

4. Select the fields to be enabled for bulk editing and use the arrow button to move them to the right-hand side.

<figure><img src="../.gitbook/assets/image (214).png" alt=""><figcaption></figcaption></figure>

5. Repeat the same steps for the custom fields in the Bulk Edit pop-up.

<figure><img src="../.gitbook/assets/image (196).png" alt=""><figcaption></figcaption></figure>

6. Click **Save** to save the bulk edit configuration.

<figure><img src="../.gitbook/assets/image (197).png" alt=""><figcaption></figcaption></figure>

### Result

After the configuration is saved, a notification message is displayed.

<figure><img src="../.gitbook/assets/image (198).png" alt=""><figcaption></figcaption></figure>

## Bulk edit mission data

1. Review the number of selected missions displayed in the Bulk Edit pop-up.
2. Review the list of fields selected during configuration, displayed in the Bulk Edit pop-up.
3. Choose the required values for the listed mission fields.

<figure><img src="../.gitbook/assets/image (199).png" alt=""><figcaption></figcaption></figure>

4. Click **Save**.

<figure><img src="../.gitbook/assets/image (215).png" alt=""><figcaption></figcaption></figure>

### Result

All selected missions are updated simultaneously with the values chosen in the Bulk Edit pop-up.

<figure><img src="../.gitbook/assets/image (201).png" alt=""><figcaption></figcaption></figure>
