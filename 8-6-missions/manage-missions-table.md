# Manage Missions Table

Use the missions table to customize its display, sort it, and filter it to find the missions you need.

## Before you begin

* Sign in to **Nomadia Delivery** with a user profile that has access to the **Missions** page and its missions table.

## Feature overview

* **Table action menu**: Opens **Actions - Customize the list** to choose the fields displayed in the table.
* **Available Fields / Display Fields**: The lists you use to select which fields appear on the table.
* **Column header**: Lets you sort the table in **Ascending** or **Descending** order.
* **Mission Status dropdown or shortcut button**: Filters the table by a status, such as Waiting or Picked Up.
* **Filter input field**: Lets you select conditions to create, pin, or delete a filter.
* **Load saved filter icon**: Lets you save a filter under a name and pin saved filters.

## Customize the table display

1. Click the **Table action** menu.
2. Click **Actions - Customize the list**.

<figure><img src="../.gitbook/assets/Nomadia_Layout_V1 (5).png" alt=""><figcaption></figcaption></figure>

3. Select the desired fields from the Available Fields list and click the arrow icon to move them to the Display Fields section.
4. Click **Save**.

<figure><img src="../.gitbook/assets/image (175).png" alt=""><figcaption></figcaption></figure>

### Result

The selected fields are displayed on the table.

## Sort the table

1. Click the **column header** (for example, Last Name).
2. Select **Ascending** or **Descending** order.

<figure><img src="../.gitbook/assets/image (212).png" alt=""><figcaption></figcaption></figure>

### Result

The table reorders based on the selection.

## Filter the table using mission status shortcuts

1. Click the Mission Status dropdown or shortcut button.
2. Choose the desired status, such as Waiting or Picked Up.

<figure><img src="../.gitbook/assets/image (213).png" alt=""><figcaption></figcaption></figure>

### Result

The table refreshes and shows only matching entries.

## Create a filter

1. Click the Filter input field.
2. Select the appropriate condition from the suggestions.
3. Click the Load saved filter icon.
4. Enter the appropriate name in the input field.
5. Click **Save**.

<figure><img src="../.gitbook/assets/image (182).png" alt=""><figcaption></figcaption></figure>

## Pin a filter

1. Click the Load saved filters icon.
2. Click the pin icon of the filter to pin.

<figure><img src="../.gitbook/assets/image (183).png" alt=""><figcaption></figcaption></figure>

## Delete a filter

1. Click the Filter input field.
2. Select the appropriate condition from the suggestions.
3. Click the filter option.
4. Click the **Delete** icon to delete the selected status.

<figure><img src="../.gitbook/assets/image (183).png" alt=""><figcaption></figcaption></figure>

## Tips

{% hint style="info" %}
**Find missions faster**: Use a mission status shortcut to show only matching entries, and save a filter under a name so you can reload it with the **Load saved filter** icon.
{% endhint %}

{% hint style="info" %}
**Pin your filters**: Click the pin icon of a saved filter to pin it.
{% endhint %}
