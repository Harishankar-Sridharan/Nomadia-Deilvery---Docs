# Glossary

## Overview

The words are in alphabetical order. Each definition has a link to the topic that explains it in detail.

## Terms

| Term | Meaning |
| ---- | ------- |
| **Address group** | A named set of addresses of the address list, such as **Lyon Retail**, that you assign to contractors so that they can use these addresses in their missions. See [Address List Groups for Contractors](../9-7-contractors/address-list-groups-for-contractors.md). |
| **Address list** | The master record of customer addresses that you reuse when you create missions. See [Manage Global Address List](../manage-global-address-list.md) and [Manage Address List](../9-7-contractors/manage-address-list.md). |
| **Address list visibility configuration** | A named set of address list blocks, such as the map, the contact information or the optimization constraints, that you assign to a user profile to control what its users see. See [Address List Block Visibility per User Profile](../customizetheaddresslistvisibility/address-list-block-visibility-per-user-profile.md). |
| **Agency** | An operational unit of your organization, such as a depot or a branch. Missions, users and routes belong to an agency. See [Manage Users](../7-5-manage-users/README.md). |
| **Alert threshold** | A limit that triggers an alert when an operational value is exceeded. See [Alert Management](../alertmanagement.md). |
| **Anchor row** | The last row that you selected or cleared with a normal click in a table. A Shift-click selects every row from the anchor row to the clicked row. See [Shift-Click Range Selection](../8-6-missions/understanding-the-missions-page/shift-click-range-selection.md). |
| **API key** | A secret key that an external system uses to call the Nomadia Delivery API. See [Secure API Key Management](../secure-api-key-management.md). |
| **Article** | A product that is part of a delivery and is tracked with the mission. See [Manage Articles](../manage-articles/README.md). |
| **Audit log** | The record of the changes made across the platform. See [Audit Logs](../auditlogs.md). |
| **Backup zone** | A temporary secondary sector used when the subcontractor of a primary zone is unavailable. See [Creating Backup Zone](../case-studies/creating-backup-zone.md). |
| **Booking portal** | The page where customers book or reschedule a delivery slot. See [Booking Portal](../11-9-appointment-booking-portal/README.md). |
| **Breadcrumb trail** | The bar at the top of a configuration page that shows the path to the page. Each level above the current page is a link. See [Configuration Breadcrumb Navigation](../configuration-breadcrumb-navigation.md). |
| **Bulk edit** | A change applied to several missions at once. See [Bulk Edit Mission Data](../8-6-missions/bulk-edit-mission-data.md). |
| **Container** | A parent mission, such as a pallet or a box, that groups several child missions. See [Manage Container Types](../manage-container-types/README.md) and [Container child missions](../manage-container-types/container-child-missions.md). |
| **Container type** | The kind of container, with the rules for how status, attributes and documents are inherited between parent and child missions. See [Edit a Container Type](../manage-container-types/edit-a-container-type.md). |
| **Contractor** | The customer that orders the missions from the transporter. See [Contractors](../9-7-contractors/README.md). |
| **Cross docking** | A mission flow where goods move through an intermediate hub between the mid mile and the last mile. See [Cross Docking Missions](../8-6-missions/cross-docking-missions.md). |
| **Custom action** | A button that calls an external system from a screen of the back office. See [Custom Actions](../custom-actions.md). |
| **Custom dashboard** | A dashboard of indicators that you build and customize. See [Custom Dashboards](../14-12-custom-dashboards/README.md). |
| **Custom field** | A field that you add to missions, addresses or contractors to record your own data. See [Custom Fields](../8-6-missions/custom-fields.md). |
| **Deliverer** | The driver who carries out the missions of a route with the mobile app. See [Auto-Assign Missions to Deliverers](../7-5-manage-users/auto-assign-missions-to-deliverers.md). |
| **Depot** | The building where routes start and end, and where goods are stored. See [Manage the Depots / Buildings](../case-studies/no-route/manage-the-depots.md). |
| **Document template** | A Word template used to generate documents, such as route sheets, stickers and mission extracts. See [Manage Document Templates](../manage-document-templates/README.md). |
| **Drop shipping** | A mission delivered directly from the supplier to the end customer, without returning to the agency. See [Drop Shipping Missions](../8-6-missions/drop-shipping-missions.md). |
| **eCMR** | The electronic consignment note, the digital equivalent of the paper CMR used in road transport. See [Accessing eCMR](../manage-document-templates/accessing-ecmr.md). |
| **Gantt view** | A timeline view of the routes and their stops. See [Gantt View](../ganttview.md). |
| **Geocoding** | The conversion of an address into map coordinates. See [Improve the Missions addresses geocoding](../8-6-missions/import-missions/improve-the-missions-addresses-geocoding.md). |
| **JSON export** | A file that contains one or more mission configurations, which you can import into the same account or another account. See [Import and Export Mission Configurations as JSON](../8-6-missions/import-and-export-mission-configurations-as-json.md). |
| **KPI** | A key performance indicator shown on the home page. See [Configure the Display of my KPI](../readme-1/configure-the-display-of-my-kpi.md). |
| **Mission** | A logistical flow of goods from a point of origin to a destination, such as a parcel or a pallet. See [Missions](../8-6-missions/README.md). |
| **Mission configuration** | The layout and rules of the mission creation and mission edition forms. You can clone a configuration, or export and import it as a JSON file. See [Mission Creation Configuration](../8-6-missions/mission-creation-configuration.md), [Clone a Mission Configuration](../8-6-missions/clone-a-mission-configuration.md) and [Import and Export Mission Configurations as JSON](../8-6-missions/import-and-export-mission-configurations-as-json.md). |
| **Mission log** | The complete history of the activities performed on a mission. See [Mission Logs](../8-6-missions/mission-logs.md). |
| **Mission type** | The kind of mission, such as delivery, pickup, visit or drop shipping. See [Visit – A New Mission Type](../8-6-missions/visit-a-new-mission-type.md). |
| **Multi-leg mission** | A mission tracked across several hubs and agencies, from first-mile pickup to last-mile delivery. See [Multi Leg Missions](../case-studies/multi-leg-missions.md). |
| **No Route mode** | A way of working focused on mission management and traceability, without route optimization. See [No Route Mode](../case-studies/no-route/README.md). |
| **Nomadbot** | The virtual assistant of Nomadia Delivery. See [Nomadbot](../chatbot.md). |
| **Optimization** | The calculation that builds routes from the missions, the vehicles and the constraints. See [Optimize deliveries](../simulation/simulation-deliveries-optimize.md). |
| **Postal zone** | A delivery zone defined by postal codes. See [Manage Postal Zones](../manage-studies-and-zones/manage-postal-zones.md). |
| **Pre-filter** | A filter that limits the missions loaded on the Missions page. See [Pre-filters](../8-6-missions/understanding-the-missions-page/pre-filters/README.md). |
| **Primary zone** | The main delivery sector assigned to a team or a subcontractor. See [Study Creation with Primary Zone](../case-studies/study-creation-with-primary-zone.md). |
| **Priority** | The urgency of a mission. See [Prioritizing a mission](../8-6-missions/prioritizing-a-mission.md). |
| **PUDO** | A pickup and drop-off point where parcels can be left when the customer is unavailable. See [Pudo configuration](../case-studies/pudo-configuration/README.md). |
| **Range selection** | The selection of a block of consecutive rows in a table with a click and a Shift-click. See [Shift-Click Range Selection](../8-6-missions/understanding-the-missions-page/shift-click-range-selection.md). |
| **Reception** | The check of the containers received from the field. See [Reception Management](../receptionmanagement/receptionmanagement.md). |
| **Return to contractor** | The creation of return missions for the parcels that could not be delivered. See [Return to Contractor](../return-to-contractor.md). |
| **Reverse logistics** | The flow of goods back from the customer. See [Reverse Logistics](../case-studies/reverse-logistics.md). |
| **Route** | The ordered list of stops that a deliverer carries out with a vehicle. See [Routes](../8-6-missions-1/README.md). |
| **Sectorization** | The automatic creation of balanced delivery sectors. See [Create Postal Zones by Territory Management (Sectorization)](../manage-studies-and-zones/create-postal-zones-by-territory-management-sectorization.md). |
| **Shuttle** | A transportation resource that moves goods between buildings. See [Shuttle Management](../case-studies/no-route/shuttle-management.md). |
| **Simulation** | The result of a route optimization, which you review and adjust before validating the routes. See [Simulation](../simulation/simulation.md). |
| **Status** | The stage of a mission in its lifecycle, such as Created, Loaded or Delivered. See [Customizing Status Labels](../8-6-missions/customizing-status-labels.md). |
| **Study** | A set of zones and sectors used to organize delivery territories. See [Manage Studies & Zones](../manage-studies-and-zones/README.md). |
| **Sub-status** | A detailed status that describes the progress or the result of a mission. See [Manage Substatus](../manage-substatus/README.md). |
| **Subcontractor** | A partner carrier to which the transporter delegates missions. See [Subcontractor Management](../10-8-subcontractor-management/README.md). |
| **Survey** | A form that deliverers or contractors fill in at a stage of their work. See [Configuring Customized Surveys](../15-13-configuring-customized-surveys/README.md). |
| **Ticket** | A request raised about a mission or a parcel between contractors and transporters. See [Manage Tickets](../manage-tickets/README.md). |
| **Transporter** | The carrier that uses Nomadia Delivery to plan and carry out the missions of its contractors. See [Introduction](../README.md). |
| **User profile** | A set of access rights shared by several users. See [Manage User Profile](../7-5-manage-users/6-manage-user-profile.md). |
| **Validate a route** | Confirm the routes of a simulation so that they can be used and published. See [Validate routes](../simulation/simulation-routes-validate.md). |
| **Vehicle fleet** | The vehicles used for deliveries, with their capacities and constraints. See [Manage Vehicle Fleets](../manage-vehicle-fleets/README.md). |
| **Visit** | A mission type for a visit to a customer location without a pickup or a delivery. See [Visit – A New Mission Type](../8-6-missions/visit-a-new-mission-type.md). |
